# 05 — 标签库运营 UI（待审·别名·冷启动终审）

**What to build:** 在标签库提供运营入口：查看并处理待审词（批准为标准词 / 挂为别名 / 丢弃）、维护标准词与别名、走冷启动草案预览与终审写入；待审与标准词视觉/列表可区分。用户侧表现为词表可日常进化，而不靠改配置文件或等模型自动扩库。

**Blocked by:** 02 — 标准词·别名·标签归一与待审落库；04 — 词表冷启动草案与终审写入

**Status:** resolved

**Parent:** [spec.md](../spec.md)

## Acceptance criteria

- [x] 待审词列表可打开；支持批准标准词（指定封闭组）、挂别名（指定目标标准词）、丢弃
- [x] 待审与标准词在界面上可区分；待审不混入分析候选展示为「已入库标准词」
- [x] 可维护别名与标准词所属标签组（最小增删改）
- [x] 冷启动：选择/导入草稿 → 预览草案 → 确认 commit；取消不写库
- [x] 文案使用 CONTEXT 词汇（标准词、别名、待审词、词表冷启动等）
- [x] 若 02 已提供别名扩展筛选逻辑，筛选控件侧接线可用（筛别名能命中标准词标注片）
- [x] 本票以人工验收清单为主；不强制完整 UI 自动化
