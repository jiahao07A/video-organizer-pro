# GUI 基线结果

日期：2026-10-05  
环境：Windows 10.0.26200、Intel Core Ultra 9 275HX、Python 3.13.12、PySide6 6.10.2

## 口径

- 数据库使用 `tools/video_catalog_benchmark.py` 生成的合成数据，不读取生产数据库、私人路径或真实 API Key。
- 每个规模重复 3 次；记录中位数和 p95（95 分位）。
- 查询耗时从 `VideoCatalog` 调用开始到 `VideoPage` 返回，包含首批列表列投影和结果计数。
- GUI 耗时使用 `QT_QPA_PLATFORM=offscreen`，包括主窗口创建、素材库首次首批回调和输入文本后的 180ms 防抖；不包含真实媒体缩略图解码。

## PySide6 离屏 GUI 结果（毫秒）

| 规模 | 指标 | 中位数 | p95 |
| ---: | --- | ---: | ---: |
| 50,000 | 主窗口创建 | 436.925 | 1,284.054 |
| 50,000 | 素材库首批回调 | 82.297 | 88.408 |
| 50,000 | 防抖文本搜索到结果 | 207.900 | 213.797 |
| 200,000 | 主窗口创建 | 450.596 | 454.780 |
| 200,000 | 素材库首批回调 | 315.054 | 344.704 |
| 200,000 | 防抖文本搜索到结果 | 261.750 | 266.602 |

首批 GUI 结果在两种规模下均低于 2 秒；200,000 条数据的防抖文本搜索 p95 低于 300ms。GUI 基准使用延迟页面创建，因此启动时只创建工作台，素材库、标签库和设置页在首次进入时创建并缓存。

## 技术栈结论

当前 PySide6 数据路径在合成 50,000–200,000 条数据上达到本轮建议门槛，没有证据表明需要为了性能立即制作 WebView2 或 Windows 原生对照原型。暂不引入第二套前端工具链；后续应在目标用户设备上复测真实缩略图、长时间滚动、后台扫盘/分析/导出、内存趋势和事件循环最长阻塞时间。若这些实测不达标，再按同一数据和任务口径制作局部 WebView2 原型。
