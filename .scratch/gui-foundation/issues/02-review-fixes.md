## 目标与范围

在现有 GUI 重构 `03b1da4` 基础上修复分页查询与设置生效问题，将原 GUI 改动和修复整理为一个可回退提交。随后再处理仅文档的 PR #2。

范围内：Windows 路径/排除条件、空工作范围、未命名状态、重复项、表头 SQL 排序、按路径加载完整详情、防抖保存反馈与偏好立即应用、对应回归测试与 GUI 记录。

范围外：AI 模型路由、分析重试、标签归一与人工审核、已有 ADR、生产数据库、真实素材、个人配置。工作流文档和 GitHub 模板不进入本 GUI 提交。

## 已确定方案

1. 统一 Windows 路径大小写和斜杠的 SQL 比较；空范围查询返回空，素材库 `None` 表示全库；排除参数使用 JSON 集合避免大批量 SQLite 参数上限。
2. “未命名”对应 `pending` 和 `analyzed`，保持已有筛选语义。
3. 重复项按全库非空 `file_hash` 相同判断，包含重复组内所有成员；`phash` 只反映单帧相似度，本轮不用它推断视频重复。不自动读取真实视频或为未分析素材补算哈希。
4. 表头可点击，排序列白名单映射到 SQL，排序变更重置分页；Qt 代理不对单页另行重排。
5. 单选素材按路径加载完整详情，防止列表轻量投影缺少转录而保存空值。
6. 普通偏好成功保存后发出专用信号，主窗口仅应用 UI 偏好，不重建 AI 客户端。记住工作范围开关同步路径快照；单次防抖定时器也必须显示成功状态。

## 验收与验证计划

- 先运行新增回归测试并确认失败，再修复。
- Windows 混合大小写/斜杠、目录前缀、排除后操作目标集和空范围测试通过。
- 状态组合、重复项（不包含空哈希/仅相似帧）、筛选与分页排序测试通过。
- Qt 离屏验证表头排序、详情转录、真实防抖计时和主题/字号/侧栏即时应用。
- 全量 `python -m pytest -q` 通过；暂不声称真实媒体、长期滚动或 20 万数据设备复测通过。
- `git diff --check`、`git diff --cached --check` 通过；提交中无个人配置、真实素材或生成产物。

## 风险与回滚

风险集中在 SQL 查询边界和 Qt 状态/信号；使用合成数据库和离屏控件覆盖。用单个 GUI 提交的 `git revert` 回退代码，不对原始视频作任何变更。推送前重新核对远程主干；普通快进推送，不强推 `main`。
