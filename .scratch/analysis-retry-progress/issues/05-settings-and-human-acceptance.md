## 人测清单（GUI）

1. 开始分析若干视频：可见总/本轮双进度与状态文案  
2. 列表状态列出现「分析中·… / 成功 / 失败」临时态，结束后恢复库状态  
3. 人为制造 API 瞬时失败（或弱网）：可见重试日志，部分可自愈  
4. 首轮有失败时：文案出现补跑，子进度从 0 再走，总进度不清零  
5. 分析中点「取消分析」：停止后续，不自动补跑，已成功保留  
6. 设置 → 关闭「自动补跑失败项」→ 保存 → 再分析：首轮失败后不补跑  
7. 设置调整次数后，**下一次**分析任务生效
