# 05 — 素材库页 + 勾选累加到工作范围

**What to build:** 侧边栏新增「素材库」页，呈现全部已入库视频素材（浏览/搜索/详情，与工作台列表能力对齐但不承担路径浏览主责）。用户勾选若干条目后点「累加到工作范围」，将对应视频路径并入工作范围；工作台列表随之更新。分析与高风险操作仍只在工作台。

**Blocked by:** 02 — 工作范围：替换、扫盘入库、工作台只显示范围

**Status:** resolved（实现完成，待 GUI 验收）

**Parent:** [spec.md](../spec.md) · ADR-0001

## Acceptance criteria

- [x] 侧边栏可进入「素材库」；列表展示全部已入库素材
- [x] 支持勾选多条；「累加到工作范围」将选中视频路径追加进范围（不再弹路径对话框）
- [x] 累加后切换到工作台可见新条目（若文件已在库）
- [x] 素材库不提供分析/物理重命名等与工作台抢责的操作入口（或明确禁用）
- [x] 主题切换下页面可读（沿用既有主题广播）
