# 02 — 工作范围：替换、扫盘入库、工作台只显示范围

**What to build:** 用户可通过工作台「路径 / 浏览」设定**工作范围**（多文件 + 多文件夹；默认整份替换）。设定后扫描范围内视频并入库（含未分析），工作台列表只呈现落在范围内的素材；启动时未记住范围则空列表并有明确提示。路径区能反映当前范围（如 N 项摘要）。

**Blocked by:** None — can start immediately

**Status:** resolved（实现完成，待 GUI 验收）

**Parent:** [spec.md](../spec.md) · ADR-0001

## Acceptance criteria

- [x] 工作范围为路径列表；文件精确匹配、文件夹包含其下视频（含子目录）
- [x] 「浏览」支持多文件与多文件夹，确认为整份替换
- [x] 范围变更后扫盘：新文件入库为未分析（或等价）；已存在不覆盖既有分析结果
- [x] 工作台列表 = 已入库且 ∈ 工作范围；空范围时列表为空并有提示
- [x] 路径 UI 能表达多项范围（数量或摘要即可）
- [x] 服务层测试：替换、成员判定、空范围列举、扫盘入库行为
