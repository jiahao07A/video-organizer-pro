# 04 — 工作台「累加」路径

**What to build:** 工作台在默认「浏览=替换」之外，提供「累加」入口：再选文件/文件夹后并入当前工作范围，去重并再次扫盘，工作台列表刷新为新范围内容。

**Blocked by:** 02 — 工作范围：替换、扫盘入库、工作台只显示范围

**Status:** resolved（实现完成，待 GUI 验收）

**Parent:** [spec.md](../spec.md) · ADR-0001

## Acceptance criteria

- [x] 工作台有明确的「累加」操作（与默认浏览替换区分）
- [x] 累加支持多文件与多文件夹
- [x] 累加后路径去重；列表与扫盘行为与范围变更一致
- [x] 服务层测试：累加后范围包含新旧路径且列举正确
