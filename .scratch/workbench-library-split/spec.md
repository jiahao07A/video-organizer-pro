## Problem Statement

用户在整理视频素材时，当前「工作台」同时扮演**总库存**和**当前任务台**：列表默认展示全部已入库素材，「路径 / 浏览」只能选单个文件夹，未勾选时重命名等高风险操作可能波及全库。用户无法清晰区分「我库里有什么」和「我这一批要处理什么」。

同时，AI 分析要求模型输出构图、星级、质量分、代理建议、标签权重等字段，加重输出负担，影响分类、标签、摘要等核心结果的准确率；详情、导出与重命名模板仍依赖这些字段，形成不一致。

高级筛选选项偏少，且仅挂在工作台；界面可设置项也偏少（字体、缩略图、侧栏主题切换），无法覆盖默认视图、侧栏宽度、详情面板与「记住工作范围」等日常偏好。

## Solution

1. **拆分页面**：侧边栏新增 **素材库**（全部已入库视频素材）；**工作台**只呈现当前 **工作范围** 内的素材，并仅在此执行分析与高风险操作。
2. **工作范围**：由路径集合（多文件 + 多文件夹）定义。工作台「浏览」默认**整份替换**；工作台与素材库均提供**累加**（工作台再选路径；素材库将列表勾选的视频路径并入）。变更范围时**扫盘入库**（含未分析），工作台与素材库均可见新条目。启动默认空范围并提示；设置可开启「记住上次工作范围」。
3. **分析结果瘦身（硬删）**：模型与存储只保留分类、摘要、情绪、标签；删除构图、星级、质量分、代理建议、标签权重在提示词、库表/读写、详情、导出、重命名变量中的一切使用。
4. **高级筛选增强**：工作台与素材库使用**同一套**筛选（在现有分类/标签/日期/重复上增加情绪、分析状态含是否已分析、标签任一/全部、摘要是否为空）。
5. **界面偏好扩展**：默认列表/卡片、侧栏宽度、详情默认展开/收起、主题进设置页并与侧栏同步、记住工作范围、保存后尽量立即生效。

## User Stories

1. As a 剪辑师, I want 侧边栏有独立的「素材库」页, so that 我能浏览全部已入库视频素材而不必混在当前任务里。
2. As a 剪辑师, I want 工作台只显示工作范围内的视频素材, so that 我不会被库里其它文件干扰。
3. As a 剪辑师, I want 工作台「浏览」支持一次选择多个文件和多个文件夹, so that 我能快速划定一批分散路径。
4. As a 剪辑师, I want 默认「浏览」替换整份工作范围, so that 我不会在不知不觉中堆出过大范围。
5. As a 剪辑师, I want 工作台上有「累加」按钮再选路径, so that 我可以在已有范围上追加文件夹或文件。
6. As a 剪辑师, I want 在素材库勾选若干视频后点「累加到工作范围」, so that 我能从库存挑料送进工作台处理。
7. As a 剪辑师, I want 设定或变更工作范围时自动扫描路径下视频并入库（含未分析）, so that 列表立刻出现条目而不是空白。
8. As a 剪辑师, I want 新扫到的素材同时出现在素材库, so that 总库存始终完整。
9. As a 剪辑师, I want 启动时若未开启记住范围则工作台为空并有明确提示, so that 我知道需要先设定工作范围。
10. As a 剪辑师, I want 在设置中开启「记住上次工作范围」, so that 下次打开能恢复上次路径集合。
11. As a 剪辑师, I want 分析、模拟整理、应用重命名、导出等默认只作用于工作范围, so that 不会误伤范围外的入库素材。
12. As a 剪辑师, I want 在工作台列表勾选部分行时只处理勾选项（仍须在范围内）, so that 我可以在一批里再缩小。
13. As a 剪辑师, I want 未勾选时处理工作范围内的全部素材, so that 我不必逐条勾选整批。
14. As a 剪辑师, I want 素材库提供与工作台相同的高级筛选, so that 我能在总库里用同一套条件找料。
15. As a 剪辑师, I want 按情绪筛选, so that 我能按情感基调收窄列表。
16. As a 剪辑师, I want 按分析状态（含是否已分析）筛选, so that 我能找出未分析或已分析的素材。
17. As a 剪辑师, I want 标签筛选可在「满足任一」与「同时满足全部」之间切换, so that 我能控制标签条件的松紧。
18. As a 剪辑师, I want 按摘要是否为空筛选, so that 我能找出尚未写摘要的条目。
19. As a 剪辑师, I want 继续使用分类、标签、日期、仅重复项等既有筛选, so that 原有习惯不被打断。
20. As a 剪辑师, I want AI 分析不再要求构图/星级/质量分/代理建议/标签权重, so that 模型更专注分类、摘要、情绪与标签并提高准确率。
21. As a 剪辑师, I want 详情面板不再展示已删除的分析结果字段, so that 界面与真实能力一致。
22. As a 剪辑师, I want 重命名模板与导出不再依赖已删字段（如 composition、评分）, so that 不会出现空变量或错误元数据。
23. As a 剪辑师, I want 旧的已删字段数据被硬删或忽略且无只读残留入口, so that 不会误以为还能筛评分或构图。
24. As a 剪辑师, I want 在设置中调整默认列表/卡片视图, so that 打开工作台或素材库时符合习惯。
25. As a 剪辑师, I want 调整侧边栏宽度, so that 导航区域适合我的屏幕。
26. As a 剪辑师, I want 设置详情面板默认展开或收起, so that 首屏布局符合习惯。
27. As a 剪辑师, I want 在设置页切换主题并与侧栏按钮同步, so that 不必只依赖侧栏入口。
28. As a 剪辑师, I want 保存界面偏好后尽量立即生效, so that 不必重启应用。
29. As a 剪辑师, I want 路径输入区能反映当前工作范围（如多项时显示数量或摘要）, so that 我知道现在范围里有什么。
30. As a 维护者, I want 工作范围、列表过滤与分析 schema 的行为可在服务层用自动化测试锁定, so that 后续改 UI 不易破坏规则。

## Implementation Decisions

### 架构与 ADR

- 遵循 ADR-0001：工作台 / 素材库 / 工作范围分工。
- 遵循 ADR-0002：分析结果字段硬删与保留集合。
- 产品词一律使用 `CONTEXT.md` 中的定义。

### 工作范围（领域行为）

- 引入**工作范围**为路径列表（文件与文件夹均可）；成员关系：视频路径等于某文件项，或位于某文件夹项之下（含子目录）。
- **替换**：新选择覆盖全部范围路径。
- **累加**：并入新路径；去重；已有父路径覆盖子路径时可规范化（实现时选简单正确策略，行为需可测）。
- **扫盘入库**：范围变更后扫描范围内视频扩展名文件；尚不在库则登记为未分析（或等价状态）；已在库则保留既有分析结果。
- **列表**：工作台数据源 = 已入库且落在工作范围内；素材库 = 全部已入库。
- **持久化**：界面偏好中的「记住上次工作范围」为真时，保存/恢复路径列表；为假时启动空范围。
- **操作边界**：工作台上分析、模拟整理、应用重命名、导出、回滚相关入口的默认目标集合 ⊆ 工作范围；勾选再 ⊆ 勾选集；禁止「未勾选则全库」的旧行为。

### 导航与页面

- 侧边栏增加「素材库」页；保留工作台、标签库、系统设置。
- 素材库：列表/卡片、搜索、高级筛选、详情（只读或与现有详情能力对齐但不承担路径浏览主职责）、累加到工作范围。
- 工作台：路径/浏览/累加、范围提示、高级筛选、分析与整理操作条、详情。
- 两页筛选控件能力一致，可共享同一筛选组件与参数模型；筛选状态可各自独立（不必跨页同步，除非实现成本更低且不违背产品语义）。

### 高级筛选参数（扩展）

在既有 `text / categories / tags / date_start / date_end / only_dup` 上增加至少：

- `emotions`：多选情绪
- `analysis_status` 或等价：未分析 / 已分析 /（若已有）已重命名等；须覆盖「是否已分析」
- `tag_match_mode`：`any` | `all`
- `summary_empty`：不限 / 为空 / 非空

不包含时长、分辨率等未入库技术参数。

### 分析结果 schema

- 提示词 JSON 模板与解析：**保留** category、summary、emotion、标签/标签组维度字段。
- **移除** composition、rating、quality_score、is_proxy_needed、tag_weights 的生成、存储写入、UI 展示、搜索串拼接、导出与重命名占位符。
- 数据库：停止读写上述列；迁移策略以实现简单为准（忽略列或删除列均可），产品语义为硬删、无只读兼容 UI。
- 标签展示不再依赖权重透明度/权重逻辑。

### 界面偏好

在现有字体、缩略图、主题基础上增加并读写：

- 默认视图模式（列表/卡片）
- 侧边栏宽度档位或像素
- 详情面板默认展开/收起
- 记住上次工作范围（布尔）
- 主题：设置页可改，与侧栏切换写入同一偏好键，变更广播到已创建视图

保存后对字体、主题、侧栏、默认视图、详情默认态尽量即时应用。

### 建议模块边界（无具体文件路径）

- **服务层**：工作范围状态、扫盘入库、按范围列举视频、分析提示词组装、视频写入（瘦身字段）。
- **筛选模型**：纯函数式/代理模型的 `filterAccepts` 逻辑（扩展参数）。
- **视图**：主窗导航、工作台、素材库、设置界面页、详情与筛选面板去字段。
- **导出/重命名**：去掉已删字段变量与 XMP 评分等依赖。

## Testing Decisions

### 什么是好测试

- 只断言**外部可观察行为**（给定输入路径/范围/视频记录/筛选参数 → 列表成员、状态、提示词结构、操作目标集合），不断言布局像素或私有控件树。
- 优先测服务层与筛选逻辑；GUI 冒烟可人工验收清单，不强求本轮上完整 UI 自动化。

### 测试接缝（Seams）— 请确认

本功能跨 UI 与数据，但自动化应压在**尽量少、尽量高**的接缝上：

| 优先级 | 接缝 | 锁定什么 |
|--------|------|----------|
| **主接缝** | **视频整理服务（VideoOrganizerService 或其等价门面）** | 设置/替换/累加工作范围；扫盘入库；按范围列举；分析/重命名目标集合 ⊆ 范围；分析提示词/写入 payload **不含**已删字段且**含**保留字段 |
| **次接缝** | **高级筛选判定（代理模型或抽离的纯函数）** | 情绪、分析状态、标签 any/all、摘要空/非空与既有条件组合 |
| **非自动化默认** | 主窗页面拼装、主题 QSS | 用验收清单人工点验 |

**刻意不新增**第二套业务入口：UI 只调用服务层工作范围与列表 API，避免视图内复制路径匹配逻辑。

> 实现前请确认：是否同意以「服务层主接缝 + 筛选次接缝」为准？若希望筛选也完全并入服务层单一接缝，可在 `/to-tickets` 前回复调整。

### 将测试的模块

- 工作范围：替换、累加、去重、文件夹包含子文件、空范围列举为空。
- 扫盘：新文件入库为未分析；已存在不覆盖分析结果。
- 操作边界：无勾选时目标 = 范围内全部，而非全库。
- 分析 schema：`build_analysis_prompts`（或等价）JSON 结构无已删键。
- 筛选：各新参数正反例。

### 既有测试 Prior art

- 仓库当前**几乎无**自动化测试套件；本特性引入的测试即为首批服务层/筛选回归基线，建议使用项目已有 Python 环境与最小 pytest（若尚未依赖则本特性允许新增成熟测试依赖）。

## Out of Scope

- 时长、分辨率、码率、编码等技术元数据探测与筛选。
- 自定义完整配色体系、多语言、动画偏好。
- 标签组业务规则重构、Prompt 配置中心大改（仅去掉已删字段相关提示）。
- 素材库内发起分析/物理重命名（分析与高风险操作仍在工作台）。
- AI 全自动整理全流程的新产品能力（批次确认/回滚语义保持既有，仅收紧操作目标集合）。
- 与本特性无关的 runtime-bugs 主题验收（可并行，但不阻塞本 spec 拆票）。

## Further Notes

- 实现顺序建议（供 `/to-tickets` 参考，非强制）：① 分析结果瘦身（提示词/库/UI/导出）→ ② 工作范围服务 + 工作台列表收窄 + 操作边界 → ③ 素材库页 + 累加 → ④ 高级筛选扩展并挂两页 → ⑤ 界面偏好扩展与记住范围。
- 验收时需覆盖 light/dark 下新页与筛选可读性（沿用既有主题广播机制）。
- 多路径 UI：路径框可用「N 项已选」+ 详情/tooltip 列出路径；具体控件形态由实现选择，行为以工作范围规则为准。
