# 07 — 端到端人工验收

**What to build:** 在真实桌面环境按验收口诀走通本特性：**五档可切**、**无勾选列**、**选中优先/可见全部**、**开始分析边界**、**待审左栏批准到组**、**无中转池**、**删组必改派**。产出简短通过/失败记录（可写在本票 Comments），不强制自动化。

**Blocked by:** 02 — 去选择列；03 — 开始分析；04 — 模型供应商；06 — 标签库布局

**Status:** ready-for-human

**Parent:** [spec.md](../spec.md)

## Acceptance criteria

- [ ] 设置：可建/切至多 5 个模型供应商；旧配置以「默认」可用；保存后分析用当前档案
- [ ] 列表无选择列；有选中批量只动选中；无选中批量动可见全部；筛选外不被误伤
- [ ] 开始分析：选中子集 / 可见全部 + 分析目标集（含强制重分析确认）行为正确
- [ ] 标签库：左待审批准到组；右侧无中转池；跨组移动可用
- [ ] 删非空组须改派；唯一组删不掉；导入/批准无组被拒
- [ ] 破坏性操作确认文案条数与语义正确
