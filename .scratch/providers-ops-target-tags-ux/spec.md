## Problem Statement

用户需要在设置中保存并切换多套 AI 连接（不同中转/模型），但当前只有**单套** API Key / Base URL / 任务模型名，换环境要反复手改，容易串配置。

工作台与素材库列表依赖独立「选择列」勾选框做批量操作，与资源管理器心智不一致；勾选与行高亮两套选中并存，分析/导出/删除边界难讲清。「开始分析」本应按「选中优先、否则全部」工作，但实现与产品表述仍绑在勾选集合上，且「全部」边界（是否含筛选外）不清晰。

标签库虽已有分栏、拖拽、待审弹窗与近义巡检，但日常路径割裂：待审在弹窗里批完还要回分栏再挪组；中转池与待审概念易混；顶栏按钮与热力图挤占主视觉；删除标签组仍可能把词丢回中转池。用户希望**重构标签库交互**：待审主审 + 标准词移动顺手，废除中转池，标准词必须属于某一标签组。

## Solution

1. **模型供应商（最多五个）**：每条档案含显示名、API Key、Base URL、任务模型名（分类/标签/描述）；任意时刻一个**当前供应商**；分析与标签库 AI 均用当前供应商；旧单套配置自动迁为「默认」档案。
2. **删除列表选择列**；批量操作只认**列表选中**（资源管理器常用子集：单击、Ctrl、Shift、Ctrl+A、点空白取消）；无选中时操作**当前可见列表全部**（含破坏性操作，确认框写清条数与语义）。
3. **操作目标集 + 分析目标集**：「开始分析」先取操作目标集，再按状态过滤（未分析/失败必跑，已分析默认跳过，强制重新分析另开）。
4. **标签库布局**：左侧固定**待审面板** + 右侧仅**标签组栏**；废除中转池与默认热力图；原 pool 词降为待审（素材上字符串保留）；删非空组须整组改派；禁删唯一组；导入标准词必须指定目标组；标准词跨组为**标签移动**；近义巡检与标签使用统计为次要入口。

## User Stories

### 模型供应商

1. As a 剪辑师, I want 在设置中保存最多五个模型供应商档案, so that 我能在不同 API 环境间切换而不反复手填。
2. As a 剪辑师, I want 每个档案包含显示名、API Key、Base URL 以及分类/标签/描述三个任务模型名, so that 换供应商时连接与模型名一起切换。
3. As a 剪辑师, I want 明确看到并切换「当前供应商」, so that 我知道下一次分析会打到哪套配置。
4. As a 剪辑师, I want 切换当前供应商并保存设置后后续 AI 请求立即使用新档案, so that 不必重启应用。
5. As a 剪辑师, I want 编辑 Key/URL/模型名后通过「保存设置」落盘, so that 误改可在保存前放弃。
6. As a 剪辑师, I want 已有五个档案时新增被拒绝并提示, so that 不会无限堆档案。
7. As a 剪辑师, I want 删除某个档案后若删的是当前供应商则自动切到另一个, so that 始终有可用当前供应商。
8. As a 剪辑师, I want 删到只剩需要时仍至少能编辑一条档案（含空档案）, so that 不会彻底失去配置入口。
9. As a 剪辑师, I want 升级后旧的单套 Key/URL/模型自动变成显示名为「默认」的当前供应商, so that 我无感迁移。
10. As a 剪辑师, I want 分析进行中切换供应商不中断本轮任务, so that 进行中的批次结果可预期。
11. As a 剪辑师, I want 标签库侧 AI（待审建议、冷启动、近义巡检）也使用当前供应商, so that 全应用共用一套生效连接。
12. As a 维护者, I want 供应商解析与迁移逻辑可单测, so that 设置 UI 改动不会弄丢 Key 或串模型名。

### 列表选中与操作目标集

13. As a 剪辑师, I want 列表不再显示「选择」勾选列, so that 界面更像文件管理器、少一列干扰。
14. As a 剪辑师, I want 单击选中一行, so that 我可以快速点开详情预览。
15. As a 剪辑师, I want Ctrl 点选/取消多行, so that 我可以拼出任意子集。
16. As a 剪辑师, I want Shift 连选一段, so that 连续多条操作更快。
17. As a 剪辑师, I want Ctrl+A 全选当前可见列表, so that 筛选后一键全选可见项。
18. As a 剪辑师, I want 点列表空白取消选中, so that 我能明确进入「无选中 = 操作可见全部」状态。
19. As a 剪辑师, I want 方向键移动焦点并可配合 Shift 扩展选中, so that 键盘也能多选。
20. As a 剪辑师, I want 卡片视图与列表视图同一套选中语义, so that 切视图不换脑。
21. As a 剪辑师, I want 工作台与素材库同一套列表选中规则, so that 两页心智统一。
22. As a 剪辑师, I want 有列表选中时批量操作只作用于选中项, so that 我可以局部分析/导出/移出。
23. As a 剪辑师, I want 无列表选中时批量操作作用于当前可见列表全部, so that 不必先全选再点按钮。
24. As a 剪辑师, I want 「可见全部」受高级筛选约束, so that 不会误伤被筛选藏起的条目。
25. As a 剪辑师, I want 工作台批量操作不得越过工作范围, so that 不会误伤范围外入库素材。
26. As a 剪辑师, I want 移出工作范围/取消入库/物理整理等破坏性操作也遵循同一操作目标集, so that 规则只有一套。
27. As a 剪辑师, I want 破坏性操作确认框写明将处理的条数与产品语义, so that 无选中点删除时我仍知道会动多少条。
28. As a 剪辑师, I want 素材库「累加到工作范围」使用操作目标集, so that 与分析/删除选中规则一致。
29. As a 剪辑师, I want 模拟整理/导出/重命名同样基于操作目标集, so that 不会残留勾选列逻辑。
30. As a 维护者, I want 操作目标集解析可单测, so that UI 选中实现变化不会改业务边界。

### 开始分析

31. As a 剪辑师, I want 点「开始分析」时默认分析当前操作目标集中符合分析目标集规则的视频, so that 选中即分析、未选则可见全部。
32. As a 剪辑师, I want 未分析与分析失败必进入分析队列, so that 不会假完成。
33. As a 剪辑师, I want 已分析默认跳过, so that 不重复烧 API。
34. As a 剪辑师, I want 勾选「强制重新分析」时已分析也可进入目标集且成功后整份覆盖, so that 词表/模型升级后可刷新。
35. As a 剪辑师, I want 强制重新分析前有确认, so that 不会误覆盖人工改过的内容。
36. As a 剪辑师, I want 分析结果写入前仍经标签归一, so that 半封闭规则不被绕过。
37. As a 维护者, I want 分析仍走既有分析目标集接缝, so that 只替换候选路径来源为操作目标集。

### 标签库：布局与待审主路径

38. As a 剪辑师, I want 标签库左侧固定待审面板（列表 + 批准到组 / 挂别名 / 丢弃 / AI 建议）, so that 审核不必再进独立弹窗主流程。
39. As a 剪辑师, I want 右侧只看到各标签组栏而不再有中转池栏, so that 标准词归属清晰。
40. As a 剪辑师, I want 批准待审词时必须指定目标标签组, so that 词直接成为该组标准词。
41. As a 剪辑师, I want 批准后不经中转池二次拖拽, so that 审核与进组同路径完成。
42. As a 剪辑师, I want 待审词与标准词在界面上可明显区分, so that 我不把未入库词当库词用。
43. As a 剪辑师, I want 挂别名时能对照右侧已有标准词, so that 决策更快。
44. As a 剪辑师, I want AI 建议仍须我确认才写入, so that 词表不被静默污染。
45. As a 剪辑师, I want 近义巡检放在顶栏「更多」等次要入口, so that 主视觉留给待审与分栏。
46. As a 剪辑师, I want 标签使用统计（原热力图）默认不占主界面且可从次要入口打开, so that 垂直空间留给审核与移动。

### 标签库：废除中转池与迁移

47. As a 剪辑师, I want 标准词始终属于某一标签组, so that 不存在「已入库但无家可归」的词。
48. As a 剪辑师, I want 升级后原中转池/未分组标准词自动变为待审词, so that 我可以重新批准进组。
49. As a 剪辑师, I want 这些词已贴在视频上的文字保留在素材上, so that 历史标注不丢。
50. As a 剪辑师, I want 批准回组后素材标注可再按标准词与归一规则对齐, so that 库与素材最终一致。
51. As a 剪辑师, I want 界面与文案不再出现「中转池」作为可用落点, so that 概念不回潮。

### 标签库：移动、删组、导入

52. As a 剪辑师, I want 通过拖拽把标准词从一个标签组移到另一个, so that 日常改组很快。
53. As a 剪辑师, I want 通过右键「移动到」批量改组, so that 不依赖拖拽也能完成。
54. As a 剪辑师, I want 标签移动只改所属组不改标准词正文, so that 素材上的标准写法保持稳定。
55. As a 剪辑师, I want 删除非空标签组时弹出整组改派选择目标组, so that 组内词有去处后再删组。
56. As a 剪辑师, I want 空标签组可以直接删除, so that 清理空壳组不费事。
57. As a 剪辑师, I want 无法删除库中唯一剩余的标签组, so that 始终有组可挂标准词。
58. As a 剪辑师, I want 导入 TXT/词表写入标准词前必须为每条或每批指定目标组, so that 导入不再进中转池。
59. As a 剪辑师, I want 未指定目标组时不能写入标准词, so that 不会产生无组标准词。
60. As a 剪辑师, I want 在组内快速添加/改名/删除标准词与管理别名仍可用, so that 日常管词不被待审重构打断。
61. As a 剪辑师, I want 冷启动/加载词表与 Prompt/组规则入口仍可达但不必抢主视觉, so that 偶尔用的运营能力不丢。

### 回归与一致性

62. As a 剪辑师, I want 去掉勾选列后列显示偏好与列宽偏好仍正常（无「选择」列或忽略之）, so that 旧偏好不炸界面。
63. As a 维护者, I want 全量自动化测试覆盖 S1–S4 接缝, so that 后续 UI 迭代不回退规则。

## Implementation Decisions

### 模块与职责

- **操作目标集解析（S1）**：新增与分析目标集同风格的纯逻辑模块（或并入现有 ops 范围解析旁）。输入：`selected_paths`（可空）、`visible_paths`、可选 `work_scope` 约束；输出：有序路径列表。规则：非空选中 → 选中（再与工作范围求交，若适用）；空选中 → 可见列表全部。
- **分析流水线（S2）**：工作台「开始分析」与相关批量入口改为：先 S1 得操作目标集，再调用既有分析目标集过滤；移除对模型 `checked_items`/选择列的依赖。
- **列表/卡片 UI**：去掉选择列与 CheckState 列逻辑；统一 ExtendedSelection 行为（Ctrl+A、点空白清除）；工作台与素材库共用同一「收集选中路径 / 可见路径」辅助逻辑。
- **模型供应商（S3）**：设置结构扩展为供应商档案列表 + `current_provider_id`（名称以实现为准）；加载时若无档案则从旧 `api.key` / `api.base_url` / `api.model_personalization` 迁移为「默认」；运行时解析函数把「当前供应商」投影为 AI 层仍消费的有效 Key/URL/模型字段（或直接读档案，避免双源真相——**推荐单一真相：档案列表，旧扁平字段仅作迁移源或兼容写穿**）。
- **设置 UI**：AI 页提供档案列表（≤5）、当前切换、字段编辑、新增/删除；保存走既有设置持久化。
- **标签库 UI**：左待审面板 + 右组栏；移除中转池栏与默认热力图；顶栏收敛，近义/统计/冷启动等进「更多」或等价次要入口。
- **中转池废除（S4）**：升级路径把 dimension 为 pool/未分组的标准词转为待审词记录并移出标准词表；**不**批量清空视频上已有字符串标签。
- **删除标签组**：非空 → 强制选择目标组并整组标签移动后删除；唯一组不可删。
- **标签导入**：向导与落库 API 拒绝无目标组的标准词写入；去掉「移到中转池」选项。
- **批准待审**：API/UI 强制 `group_id`；成功后出现在对应组栏。

### 交互摘要

| 场景 | 行为 |
|------|------|
| 无选中 + 开始分析 | 可见列表 → 分析目标集过滤 |
| 有选中 + 开始分析 | 选中路径 → 分析目标集过滤 |
| 无选中 + 删除 | 确认后对可见列表全部执行移出/取消入库 |
| 切换供应商 | 保存后再生效；进行中分析不中断 |
| 批准待审 | 必须选组 → 成标准词 |
| 删非空组 | 整组改派 → 删组 |

### 与既有 ADR

- **ADR-0001**：工作范围边界不变；操作目标集在工作台侧不得越出工作范围。
- **ADR-0004**：待审/归一/禁止模糊贴词不变；本特性只改待审 UI 主路径与 pool 迁移，不绕过人工确认。

### 不做的实现选择

- 不实现框选矩形。
- 不并行多供应商跑同一批分析。
- 不恢复中转池栏。
- 不把近义巡检做成默认首页。

## Testing Decisions

### 什么是好测试

- 只断言**外部可观察行为**：操作目标集路径集合、分析目标集包含/排除、供应商迁移与解析结果、pool→待审后标准词表与待审队列成员、素材标签字符串是否保留、删组改派后组归属、导入无组拒绝、批准无组拒绝。
- 不断言 Qt 像素、控件树、真实网络调用。
- AI 与设置 IO 可注入/临时目录。

### 测试接缝（已确认 A）

| ID | 接缝 | 锁定什么 |
|----|------|----------|
| **S1** | 操作目标集解析 | 有选中用选中；无选中用可见列表；工作台与范围求交 |
| **S2** | 分析目标集 | 既有状态规则；候选来自 S1 |
| **S3** | 模型供应商解析/迁移 | 旧配置→默认档案；当前投影；上限 5；删当前后切换 |
| **S4** | 中转池废除与组归属 | pool→待审且素材字符串保留；整组改派；禁删唯一组；导入/批准必须带组 |

**刻意不自动化默认**：列表键盘手感、点空白清除、待审左右布局像素、热力展开动画、真实 API 分析。

### 将测试的行为清单

- S1：选中子集、空选中、空可见列表、选中含范围外路径时的裁剪。
- S2：S1 输出再叠加 pending/analyzed/force。
- S3：无档案加载迁移；五档满拒绝新增；解析当前 Key/模型。
- S4：pool 词变待审；视频 tags 字符串仍在；删组改派；唯一组删除失败；导入缺组失败；批准缺组失败。

### Prior art

- `tests/test_analysis_targets.py`、`test_ops_filter_scope.py`、`test_settings_persist.py`、`test_tag_normalize.py`、`test_work_scope.py`：纯函数/服务层 + pytest + tmp_path。

## Out of Scope

- 框选（矩形拖选）。
- 超过五个供应商档案、多供应商并行分析。
- 删除磁盘视频文件。
- 重做冷启动算法、近义算法本体（仅入口层级与组落点约束）。
- 重新设计工作范围模型或高级筛选条件集。
- 卡片字段逐项显隐、新导出格式。
- 以真实在线大模型作为 CI 必过。
- 完整视觉重设计（图标体系、动效）。

## Further Notes

- 验收口诀：**五档可切** + **无勾选列** + **选中优先/可见全部** + **分析真进队** + **待审左栏批准到组** + **无中转池** + **删组必改派**。
- 与 `analysis-library-ux-tag-ai`：消费其分析目标集与强制重分析语义；本特性替换「勾选」为「列表选中/可见列表」。
- 与 `tag-system-depth`：消费归一/待审/别名边界；废除中转池是产品层 hardening，不放松 ADR-0004。
- 建议拆票顺序：S1 操作目标集 → 列表去勾选接线 → S2 分析入口 → S3 供应商 → S4 标签库（可与 S3 并行）。
- 实现前若「旧扁平 api 字段是否写穿」需定一种：推荐**档案为唯一真相**，保存时可选同步扁平字段供旧代码过渡，过渡期后删除扁平写路径。
