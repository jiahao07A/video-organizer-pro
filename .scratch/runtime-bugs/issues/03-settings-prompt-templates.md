## 现象

系统设置 →「Prompt 模板」页内容看起来不完整（文案短、字段少，或改了也不像生效）。

## 验证结果

**已确认存在产品/实现脱节（代码级）。** 用户主观“不完整”与实现事实一致，但**目标修复形状需你拍板**。

### 事实 1：设置页只编辑 `settings.json` 里三份短 Prompt

键名：

- `prompts.video_classification`
- `prompts.tag_generation`
- `prompts.content_description`

默认值是各一两句的短中文说明。

### 事实 2：主分析链路**完全不读**上述三键

`AIHandler.analyze_video` 实际组装方式：

1. `tag_config.global_settings.system_prompt` 作为系统提示头
2. 每个 `tag_groups[].rules.local_prompt` + 选标约束拼进 user prompt
3. 动态 JSON 结构（category / summary / emotion / 各维度字段等）

全仓库检索：`prompts.video_classification` 等**仅出现在设置 GUI 读写**，服务层分析路径零引用。

### 事实 3：真正可编辑“生效 Prompt”的入口在别处

- 标签库 → **Prompt 配置**（`PromptConfigCenter`）→ 编辑 `system_prompt` 等，写入 `tag_config`
- 各标签组规则里的 `local_prompt`

### 事实 4：设置页也没有覆盖分析实际用到的结构

设置页没有：

- 全局 `system_prompt`
- 分维度 `local_prompt`
- 输出 JSON 字段说明的可视化

因此即使用户把三框写得很长，**当前主分析仍可能完全无视**。
