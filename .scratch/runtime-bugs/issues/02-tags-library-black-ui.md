## 现象

GUI「标签库管理」页面视觉上几乎全黑，标签芯片/列表难以辨认或看起来像空白黑屏。

终端伴随：

```text
QMetaObject::invokeMethod: No such method TagsView::load_data_silent()
```

## 验证结果

**部分确认（静态代码强证据；未在本机截图复现）。**

### A. 异步刷新必然失败（已确认）

- `TagsView.async_refresh_usage_counts` 在后台线程刷新后调用：
  `QMetaObject.invokeMethod(self, "load_data_silent", Qt.QueuedConnection)`
- 全项目 **没有任何 `@Slot` 装饰器**
- PySide6 要求被 `invokeMethod` 的 Python 方法必须是 Qt Slot，否则会报 “No such method”
- 影响：使用次数热力图/计数的静默刷新不会发生

### B. 视觉“全黑”的高概率根因（代码级推断）

标签库视图大量**硬编码深色**样式（如 `#1a1a1a`、`#262626`、`#1f1f1f`），而标签芯片 `TagChipDelegate` 颜色取自 **控件 palette**（`window` / `windowText`）。

用户当前 `settings.json` 中 `ui_preferences.theme` 为 **`light`**：

- 主窗口走浅色全局 QSS
- 标签库分栏仍是深色硬编码背景
- 芯片用浅色主题 palette（深色字 + 浅/灰底）或相反组合时，**对比度可能极差**，或 QListView 默认底与硬编码冲突，表现为“几乎全黑/看不清”

另外：`QListView` 使用 `IconMode` + 自定义 delegate，若 item size / 调色板异常，也会像“空黑列”。

### C. 数据加载本身

- `tag_config.json` 中存在测试标签组与标签；`load_data` 逻辑会装入模型
- **不像**“完全没有数据”的唯一解释；更像渲染/主题/Slot 问题

## Agent Brief

**Category:** bug  
**Summary:** 标签库管理页在深色硬编码 + 全局主题 palette 混用下可读性崩溃，且 `load_data_silent` 未注册为 Qt Slot，导致异步刷新失效。

**Current behavior:**

1. 进入「标签库管理」时，分栏/列表区域接近全黑或标签几乎不可见。
2. 后台刷新标签使用次数后，Qt 报 `TagsView::load_data_silent` 不存在，静默更新失败。
3. 全局主题（light/dark）与标签库局部硬编码色板不一致。

**Desired behavior:**

1. 在 light 与 dark 两种全局主题下，标签库各分栏标题、搜索框、标签芯片、热力图文字均**清晰可读**（对比度足够）。
2. `load_data_silent` 可通过 `QMetaObject.invokeMethod` 成功调用；使用次数刷新后芯片计数/热力图能更新，且无 “No such method” 日志。
3. 不引入新的“第三套主题系统”；优先对齐现有 `get_main_style` / palette 策略，或明确标签库跟随全局主题。

**Key interfaces:**

- `TagsView.load_data_silent` — 必须成为可调用的 Qt Slot（例如 `@Slot()`）
- `TagsView.async_refresh_usage_counts` — 跨线程回到 UI 线程的刷新路径
- `TagChipDelegate.paint` — 芯片背景/文字色来源；应与所在列表的实际背景形成可读对比
- 标签库分栏/搜索框等硬编码 QSS — 与全局 `ui_preferences.theme` 的关系需一致

**Acceptance criteria:**

- [ ] 全局 theme=`light` 时，标签库标签名与分栏标题肉眼可读
- [ ] 全局 theme=`dark` 时同样可读
- [ ] 触发使用次数刷新后，终端不再出现 `No such method TagsView::load_data_silent()`
- [ ] 刷新后 usage 变化能反映到列表或热力图（有数据时）
- [ ] 不破坏拖拽分栏、快速添加、导入等现有操作入口

**Out of scope:**

- 标签组业务规则重构
- Prompt 配置中心（issue 03）
- 详情面板 `check_spelling`（issue 01）
- 设计全新视觉体系（只修可读性与 Slot）
