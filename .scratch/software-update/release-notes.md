# v0.0.1-rc2 测试版：软件更新

- 新增“系统设置 → 软件更新”，支持后台检查、更新说明、下载进度和取消下载。
- 默认只接收正式版，可以主动开启测试版本；下载与安装始终由用户确认。
- 安装前保存设置、备份素材库与标签配置，并要求结束后台任务及其他实例。
- 新增官方离线更新包导入；损坏或来源验证失败的更新包禁止安装。
- 安装后确认仍使用原素材库；更新未完成时保留数据和备份，并提供恢复指引。
- 安装向导支持简体中文。
- 修复取消更新后切换素材库受阻、原库损坏时的启动门禁、复查更新丢失待安装状态，以及临时文件只读导致下载无法结束的问题。
- 修复最高版本的平台不适用时阻断后续适用版本的问题；清单签名错误仍明确报错。

首次使用需要手动安装此版本，之后才可使用应用内更新。ZIP 旧版用户请先备份，再安装并选择原管理数据目录。

这是测试版本，请先使用少量测试素材验收。既有首次数据升级对话框的自动测试偶发超时仍单独跟踪；不表示所有旧数据组合均已验证。
