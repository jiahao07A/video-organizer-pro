# 安装版更新机制

Status: claimed
GitHub Issue: #51
Branch: feat/51-software-update

## 目标与边界

后台发现 GitHub 新版，用户确认下载，校验签名及摘要，备份后安全退出安装，启动核对原数据目录。
Windows x64 安装版优先；正式版默认，测试版可选；离线导入同样校验。
不做 ZIP 自动替换、增量更新、强制安装、自动降级或备份自动清理。

## 验收与风险

覆盖版本排序、历史 RC 错误标记、签名/摘要错误、下载取消、限流和空间不足；
覆盖任务运行、设置未保存、备份失败、多实例、安装取消、数据目录丢失及更高数据版本。
安装与数据迁移分离：Inno Setup 管程序，现有数据备份与启动升级协调器管数据。
失败保留更新会话、管理数据快照和旧版下载入口；恢复前保护当前数据，禁止静默打开空库。
发布使用独立构建输出目录，不运行 build.py，不批量删除文件。
