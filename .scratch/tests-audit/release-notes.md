# Video Organizer Pro 0.0.1-rc6

Windows x64 预发布版本。安装前请备份管理数据并正常退出旧版。

## 新增与改进

- 新增分析失败处理中心：按原因、阶段、状态码、供应商、模型、时间与400历史筛选，查看错误依据和历史。
- 手动重试支持选中项或全部筛选结果、分阶段供应商和模型、请求预算、并发与间隔、取消和结果统计。
- 新增主动AI错误诊断，错误分组脱敏后发送，诊断缓存可刷新；应用建议先预览，确认后才重试。
- 修复重试后列表不同步、400历史查询遗漏、状态文案混乱、重命名后范围清空；优化批量重命名。
- 修复更新现有记录消耗后续入库编号的问题；已有编号不自动重排。
- 改进连接编辑入口、键盘行为、小屏布局、历史全文阅读和取消反馈。
- 清理共享测试辅助与Qt资源管理，补强大范围查询、筛选、配置持久化、诊断脱敏、抽帧颜色及指标保存测试。

## 验证与限制

全量测试669通过、9项显式压力场景跳过；25条既有Qt弃用警告。7种故障注入均被回归测试捕获。安装包内68个项目模块与源码一致，无用户配置、数据库、日志或素材；隔离目录副本主窗口启动与正常退出通过。最终安装器编译成功，本轮未在正式目录执行安装。

数据库从版本2升级到3，升级前保留备份；回退旧程序须恢复升级前数据。真实供应商、桌面缩放/多显示器及长时间运行仍需结合自己的环境验收。

## 安装与更新

运行VideoOrganizer-v0.0.1-rc6-setup-win-x64.exe。应用内更新需开启接收测试版本；离线更新同时下载安装包、update.json和update.json.sig。清单使用Ed25519签名，安装包核对SHA-256；该签名不等同Windows Authenticode签名。
