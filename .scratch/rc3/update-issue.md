# [Feature] 更新使用 GitHub 优先及固定镜像网络兜底

背景：GitHub 国内网络不稳定会阻止更新检查或下载。
目标：默认请求官方 GitHub，网络失败时自动使用一个实测的固定 HTTPS 镜像，并清楚显示兜底状态。
范围：发布发现、清单与签名、安装包下载的网络故障兜底、固定路径和重定向校验、测试与用户文档。
范围外：修改签名信任根、对验签失败尝试绕过、不受限代理、自定义任意 URL、AI 请求代理。
验收：官方成功不访问镜像；连接/超时/限流/服务故障可兜底；取消不触发镜像；镜像错误可重试；签名/摘要或来源错误不能导致执行。镜像上只发送公开更新 URL，不发送素材/配置/API Key。
风险与回滚：镜像为第三方服务，签名和摘要独立验证不变；固定允许路径，每次重定向重验。撤回网络兜底即可回到 GitHub 优先旧流程，不变更数据。
验证：本地 Qt HTTP 故障注入和实际公开发布列表/资产测试；与既有更新回归及独立子代理审查。
规格：.scratch/rc3/spec.md。
