### 镜像实现决定

仅固定 gh-proxy.org/https://api.github.com/repos/<固定仓库>/releases 及 gh-proxy.org/https://github.com/<固定仓库>/releases/download/… 两类地址。官方连接错误、超时、429、5xx和明确限流403时，同一次传输至多尝试镜像一次；取消、磁盘/文件失败、响应超限、不可信重定向、TLS证书失败、验签/摘要失败均不触发镜像。官方部分下载失败后先截断该单个part文件再重下；不承诺续传。
每一新请求仍官方优先，mirror只承载公开更新请求；UI展示本次是否使用镜像，官方和镜像都失败则保留可重试提示。

## 验收与风险

素材诊断只读源文件和已有配置/数据库；对外只用用户已配置的分析服务和原有图像请求，不创建或修改生产素材库。不得输出 Key 或图像 base64。
镜像请求只允许固定仓库公开发布列表/资产路径；所有重定向逐个校验，恶意地址/清单/安装包不能执行。镜像断网保留可重试状态；GitHub 恢复后下次请求仍官方优先。镜像没有可用 JSON API 时不得解析不可信网页当作已验证发布信息。
风险：第三方镜像可用性及请求边界；以签名和摘要保证执行来源，用定向网络测试和伪造响应覆盖安全边界。回滚只撤回本轮代码，不变更用户配置、数据和已发布 rc2 资产。
