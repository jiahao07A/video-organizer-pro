# v0.0.1-rc3 测试版

- 软件更新优先访问 GitHub；连接失败、超时、明确限流或服务故障时，自动尝试固定国内镜像 gh-proxy.org 一次。发布列表、清单、签名和安装包使用相同兜底规则。
- 镜像只传输公开更新资产；客户端继续验证官方清单签名及安装包大小、SHA-256。取消、证书/来源错误、磁盘错误及签名/摘要失败不会触发镜像。
- 改善 HTTP 400 `image_url unsafe` 的提示，说明这是 AI 服务对本次图像输入的拒绝，不自动重试、不改变图像或切换供应商。

素材诊断边界：用户报告的个别素材在本地无缓存真实请求8次均成功，新旧实际分析模块和关键解码依赖一致，视频全部帧可解码。目前尚未复现原始400，不能宣称服务端拒绝根因已修复或确认rc2分析回归。

用户现场复测已确认rc2可以成功分析该素材。完整回归488项通过，双子代理review未发现确定新增缺陷；隔离安装、启动结果核对及二次覆盖安装数据保留验证通过。

安装方式：运行Windows x64安装包。应用内接收此RC版本需开启“接收测试版本”；离线导入需同时下载安装包、update.json及update.json.sig。

既有交互安装默认重启时序、真实断电与两版已公开签名版本的线上完整升级仍未验证。
