## 目标和背景

设置中心涉及模型供应商、任务模型路由、Prompt、界面偏好、分析重试、自动批次补跑、XMP、音频转录和导出。用户需要知道当前实际生效的配置、什么时候生效以及会产生什么文件或费用副作用，而不应在多个设置页之间自行推断。

## 范围内

- 在设置中心顶部提供当前生效配置摘要：当前供应商、六槽任务模型路由、Prompt 版本、标签库版本和最近连接测试结果。
- 明确视频分类、标签生成、内容描述、待审词 AI、近义巡检、标准词 AI 助手六槽的实际供应商和模型回退关系。
- 明确自动 XMP、音频转录、自动批次补跑和导出配置的开启状态、作用时机和影响。
- 区分自动保存与手动保存的设置类别，并说明保存后对新请求生效、不会静默切换进行中的分析。
- 提供模型供应商连接测试、恢复默认布局和配置回看入口。
- 在设置与开始分析/整理附近保持当前生效状态一致。

## 范围外

- 不增加超过五个模型供应商档案或恢复“全局唯一模型”路由。
- 不把冷启动 AI 分簇加入六个任务模型路由槽。
- 不在本议题更改 API Key、API Base URL 的存储安全方案。
- 不让进行中的分析因切换供应商或路由而中断或静默改用新配置。
- 不将设置页改造成任务中心或标签库主工作区。

## 验收标准

- 用户无需打开多个设置页即可知道当前供应商及六个 AI 功能槽的实际回退/指定关系。
- 用户在开始分析前能确认 XMP、音频转录、自动批次补跑和导出等副作用状态。
- 自动保存和手动保存的设置有明确提示；保存后只影响新请求，进行中的分析保持原解析结果。
- 连接测试能显示成功、鉴权失败、网络失败或模型不可用等可行动结果，且不泄露凭据。
- 恢复默认布局能处理旧列宽索引和文件名列宽异常，并明确影响范围。
- Prompt、标签库和模型配置的版本/生效时间可以在任务记录中回看。

## 依赖与约束

- 依赖 ADR-0006 的模型供应商、当前供应商和任务模型路由语义。
- 依赖 03 的自动 XMP 和恢复默认布局安全提示，依赖 04/05 的版本追溯字段。
- 供应商最多五个；冷启动 AI 分簇当前停用，不占路由槽。
- 不在文档、截图或任务记录中暴露 API Key、完整服务地址或其他敏感配置。

## 风险与回滚

- 当前生效配置若与实际请求解析不一致，会造成模型选择、费用和结果追溯错误；应由同一配置解析来源驱动摘要和请求。
- 迁移旧版单套配置时，需保留 ADR-0006 的“默认”供应商迁移规则，并验证六槽回退。
- 设置 UI 可回退到原布局，但连接测试、迁移和配置数据变更需有备份与恢复方案；不应通过删除用户配置解决异常。

## 验证计划

- 验证五个供应商档案、当前供应商回退、六槽单独指定和旧配置迁移。
- 验证切换供应商/路由不影响进行中的分析，新请求使用新配置。
- 验证自动保存、手动保存、连接测试、自动 XMP、补跑和恢复默认布局提示。
- 检查所有测试输出和截图均不含 API Key、私人路径或真实素材信息。
