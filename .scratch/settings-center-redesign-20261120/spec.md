# 设置中心职责重构与交互重设计

Status: completed
GitHub Issue: #85
Branch: feat/85-settings-center-redesign

## 背景
设置页虽已有左侧分类，但供应商连接、任务模型、处理参数、提示词、监控覆盖和导出选项仍然混杂，职责重叠、重复入口、保存反馈不一致。

## 目标
按设置实际影响的工作重构设置中心；分开 AI 连接和任务模型；让全局监控默认与目录覆盖在各自正确上下文中编辑；统一保存反馈。

## 范围内
- 分组导航：工作区、AI 工作流、素材处理、输出与维护；页面分别负责界面、连接、模型、Prompt、视频分析、失败处理、监控默认、命名导出、数据维护。
- 设置目录记录控件、页面、卡片、配置路径、存储目标、作用范围、生效时机、高级和恢复分组元数据。
- AI 连接维护最多五个供应商档案、Key、Base URL、默认连接、连接测试；模型分配页维护供应商默认模型和六类任务路由及有效来源。
- 监控目录覆盖规则移入对应监控任务，逐项继承全局；设置中心只管理全局默认。
- 普通设置 800ms 自动保存；Key、URL、Prompt 失焦立即提交；独立存储目标独立反馈，失败保留内容，绝不在状态中显示密钥。
- 卡片级恢复只影响本卡片；全部恢复界面、分析、路由、提示词、导出、监控规则，保留供应商凭据、监控目录与启用状态、数据库与素材、数据目录，并清除任务覆盖使其继承全局。
- 验证设置职责唯一性、Qt 导航/搜索、自动保存/失败、AI 路由、监控继承、复位、双分辨率和重启持久化。

## 范围外
不改配置文件结构/键、AI 路由及处理/监控/导出业务规则；不引入框架依赖；不覆盖或纳入现有未提交改动和 scratch 产物。

## 验收标准
- [ ] 每个可编辑选项只有一个入口，职责、作用范围、存储和生效时机明确。
- [ ] 三种并发分别明确对应整条分析、图片准备、新素材缩略图。
- [ ] AI 连接与模型选择分开；测试连接不会自动选择模型或切换默认连接。
- [ ] 普通重试、HTTP 400 恢复、自动 XMP、显式导出职责分明。
- [ ] 自动保存、失焦提交、存储失败独立反馈、密钥脱敏正确。
- [ ] 监控任务覆盖编辑/继承正确，全部恢复保留任务和目录。
- [ ] 双分辨率 1280x720、1024x768 检查导航、滚动、状态、Tab 顺序；重启后值一致。

## 依赖与约束
遵守 CONTEXT.md 和 ADR 0005/0006/0007/0008/0011/0013；继续使用现有 PySide6、SettingsManager、标签配置保存和监控服务。保留当前工作区修改和 scratch 文件，不纳入改动。

## 风险、回滚与数据影响
设置文件和标签配置可能分别写成功/失败，需独立显示并保留重试内容。监控覆盖空值具有继承语义，移动编辑器不得改变。无格式迁移；代码可回滚，全部恢复不触碰素材、数据库、API连接、监控目录或数据位置。

- [ ] 卡片复位、全局复位保留范围、任务继承。
- [ ] 设置和 GUI 回归测试、双分辨率与 Tab、重启持久化。
