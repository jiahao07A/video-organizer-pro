## 要交付的行为

维护者能用相同合成输入与明确计时口径证明优化有效、失败可恢复；普通启动目标 2 秒达成才宣称完成，否则报告差距与原因。前置任务各自完成正确性测试，本任务补充完整组合验收。

## 范围内

复用固定原版基线，完整进程级启动测量、大库日常读写/导出/迁移与内存/响应记录、跨任务故障验收、Windows 开发/打包走查、最终操作与维护说明、证据归档。

## 验收标准

- [ ] 起点为父进程启动应用，终点为 UI 可操作且素材库首批记录可见；包含导入模块、初始化、路径定位和首批查询，不能只测空工作台。
- [ ] 当前 Windows 设备两种规模各至少 20 次，保留环境、全样本、中位数/p95、内存；普通启动 p95 各自目标 ≤ 2 秒，未达标如实报告。
- [ ] 首次进程与后续进程启动分别标注，升级处理/确认等待/后台媒体扫描/AI 网络耗时单独记录。
- [ ] 单条保存、批量入库/取消入库、分析收尾、显式导出以同输入对比原版，记录访问范围、提交次数、耗时、内存和响应。
- [ ] 迁移取消/中断/重复启动、过期 JSON、损坏库、权限失败、组合保存中断、恢复中断/缓存失效等回归通过。
- [ ] 搬迁后编号/分析结果/配置/内部缩略图保持，原始视频不移动、不因缺失自动取消入库。
- [ ] 全量自动测试与 Windows 人工走查有命令和证据，用户及维护文档区分已验证和未验证能力。

## 验证计划

同一设备、生成器、模式与起止，基线 `01e36b4`，临时合成库与独立进程测量。升级版本的性能与旧 GUI 离屏数据不能混作同一口径；真实配置、密钥与素材不进入测试输出。

## 约束、风险与回滚

不得调整样本、只测空壳、遗漏模块导入或删除校验来过关。发现需要生产改动时更新对应任务范围，不在最终验收偷偷加功能。测试只用临时数据，无真实数据回滚动作。

范围外：换框架/数据库、云服务、扩大功能与上传真实数据。
