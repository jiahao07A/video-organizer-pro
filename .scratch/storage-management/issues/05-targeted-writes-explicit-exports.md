## 要交付的行为

编辑一条素材只访问相关记录，分析收尾不等待全库结果重写；仍可按操作目标集或明确全库选择导出 JSON/CSV，失败不影响主数据或已有输出。

## 范围内

单条定位/许可字段更新、有界批量入库及取消入库、成功分析结果及时落库、有界缓存失效、移除分析及同类收尾隐式全库输出、显式导出 UI 和流式/批次安全输出。

## 验收标准

- [ ] 单条保存不读全库，不用过期整行覆盖并发非编辑字段；详情和列表更新一致。
- [ ] 批量处理有界事务，已提交与失败部分正确报告，原始视频不变。
- [ ] 分析成功及时持久化，取消/重启保留成功结果，不将整个任务结束前的结果只留在内存。
- [ ] 分析与同类收尾不自动全库 JSON/CSV 输出、不默认加载完整全库缓存。
- [ ] 缓存有界，写入/取消入库/恢复/目录切换正确更新或失效。
- [ ] 显式导出遵守操作目标集，全库需明确选择；按批读取，取消/失败不损坏已有输出或影响已保存主数据。
- [ ] 50,000/200,000 条合成库下记录相同输入的耗时、数据访问范围/提交次数与内存，确认不存在全库处理退化。

## 验证计划

服务行为回归、查询范围观测、分析取消/失败、批量部分提交、缓存读回、导出写盘故障与 GUI 操作反馈。使用临时合成库，与固定原版相同输入比较，AI 网络和媒体解码单独计时。

## 约束、风险与回滚

保持工作范围、可见列表、操作目标集、强制重新分析及已成功落库的既有规则。部分字段更新要保留并发后台字段；失败输出仅在暂存位置处理。遵守 ADR-0007/0008，更新导出及数据访问说明。

范围外：AI/媒体性能、新筛选产品、自动同步结果文件、云存储、物理整理事务系统重建。
