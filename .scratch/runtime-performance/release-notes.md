# Video Organizer Pro 0.0.1-rc4

本版本为Windows x64测试版，建议先保留管理数据备份，再正常关闭旧版进行安装。

## 修复与优化

- 修复启动时可选FFmpeg探测造成的终端闪窗；场景检测按需加载，必要后台媒体命令隐藏控制台。
- 修复首次高并发时重复初始化AI客户端的问题，复用连接池。
- 并行设置改为“同时分析的视频数”“分析图片准备并行数”“入库缩略图并行数”，分别说明影响范围；三项上限统一为512，默认值保持不变。
- 优化素材列表摘要刷新和空预览面板初始化，减少打开页面时的阻塞。
- 标签TXT导入改为后台批量提交，导入前创建一致性快照，保留词属性与别名；补充配置投影写失败及重启中断的恢复保护，避免旧分组回灌或覆盖随后修改的组规则。
- 改善`image_url.url field is unsafe`类HTTP400的中文提示，不自动重试、不修改图片或切换供应商。

## 验证与限制

- 最终完整回归513项通过；另补512配置保存/重载与运行时上限测试，确认配置可传到执行器和抽帧闸门。
- 本地真实HTTP压力测试覆盖64、128、256同时在途请求，以及32并发连续处理1024项任务、取消、限流和超时。512是可配置上限，并不代表完成512路真实视频解码或供应商压力验收。建议逐步调高，避免CPU、磁盘和内存争用。
- 同机合成4000视频/500标签测试中，导入提交由16.22秒降至0.14秒，素材库页面构造由1.44秒降至0.024秒；不包含人工校对、AI推理或首次播放设备初始化。
- 服务端HTTP400的具体拒绝原因尚未解决。定向测试中，3个问题输入在新旧分析模块返回相同400，请求正文相同；成功对照返回200。旧版命中缓存的成功记录不能视为当前API调用成功。
- 真实断电、交互安装默认重启时序与长期高并发资源稳定性仍有未验证边界。

## 安装与离线更新

直接运行`VideoOrganizer-v0.0.1-rc4-setup-win-x64.exe`。安装器会阻止覆盖正在运行的应用，请先正常退出所有实例。

从应用内接收本版本需开启“接收测试版本”。离线更新请同时下载安装包、`update.json`和`update.json.sig`，通过软件更新页导入；客户端会验证签名、大小和SHA-256。正式渠道不会推荐此测试版。
