## 改动摘要

修复视频模型将失败说明包装成合法 JSON 后仍被记为成功的问题。统一校验新响应、持久缓存和恢复上下文；明确无效结果进入现有有界重试与失败处理，不能写成功成果、标签副作用或用于重命名。修正 Windows 托盘模式下安装冒烟将普通窗口关闭误判为进程退出的问题。应用候选版本递增到 `0.0.1-rc9`。

## 范围

### 范围内

- 响应契约、缓存/恢复上下文校验、失败分类与有界重试。
- 保护旧有效分析成果，阻止无效摘要在手动和监控改名流程中应用。
- 增补响应、缓存、并发、预览、监控、真实临时抽帧/改名和安装冒烟防御测试。
- 固定 Pydantic 依赖，新增 ADR、用户说明及 RC9 候选说明。

### 范围外

- 数据库迁移、旧库启动时批量修订、自动付费重试或自动修改真实素材。
- 供应商真实视觉能力；明确失败检测不覆盖全部模型幻觉。
- 合并前构建物发布。RC9 正式候选包从合并后的 main 重新构建、签名和隔离验证。

## 主要设计与影响

沿用现有 Pydantic、网关、重试预算、恢复预算和原子副作用边界，不改数据库结构。托盘普通关闭仍隐藏到托盘；`--smoke-exit` 只在自动化显式传入时调度应用正式退出门禁。
