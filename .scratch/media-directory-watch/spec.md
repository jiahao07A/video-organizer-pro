## 背景与目标

剪辑师的原始视频分散在多个且经常变化的目录中，手动反复选取目录处理繁琐。本任务让用户登记多个监控目录，由应用在 Windows 登录后于托盘后台运行，持续发现新视频、入库并按设置自动分析。监控只负责素材收录，不改变当前工作台范围，也不移动、重命名原始视频。

## 范围内

- 增加多个素材目录的登记、暂停、恢复、移除；设置全局递归扫描与自动分析默认值，单目录可覆盖；默认开启两项。嵌套目录按更深目录的配置，重叠扫描不重复处理。
- Windows 用户登录后可启动托盘后台进程；关闭窗口时隐藏；托盘支持重开、暂停/恢复监控、退出；登录自启可设置关闭。无有效监控目录时不启动监控。后台启动需要用户处理的提示应正常展示。
- 采用成熟的文件系统事件依赖接收变化；启动及每五分钟补扫。文件大小、修改时间连续 30 秒未变化后才入库，每 5 秒检查稳定性。
- 复用现有视频入库、分析、重试和失败处理；已入库视频不得重复入库或重复排队。自动分析不改名、不移动原文件，XMP 写回沿用现有独立设置。
- 独立保存素材缺失状态，素材库展示缺失记录。仅完整成功的目录扫描可标记未找到素材为缺失；目录不可达或扫描不完整时保留状态。文件重现时恢复可用。
- 移除监控目录仅停止后续监控。原路径已经缺失且内容指纹唯一匹配时更新原素材路径并保留分析；其他情况按新素材处理。首版不自动重分析路径不变但内容被替换的视频。
- 更新依赖、打包和安装流程，并为关键设置继承、目录优先级、扫描、稳定检测、离线/缺失恢复、移动匹配和托盘生命周期提供自动化测试。

## 范围外

- 自动将监控素材添加到当前工作台范围。
- 自动重命名、移动或重新分析已入库的同路径视频。
- 变更现有 XMP 写回规则或分析业务逻辑；仅连接现有流程。

## 验收标准

- 新增监控目录后，既有视频被扫描入库；写入稳定的新视频被入库并自动分析。
- 全局默认、单目录覆盖、嵌套目录优先级及多目录重叠去重正确。
- 关闭窗口后托盘监控继续；暂停/恢复有效；退出停止监控；登录启动后补扫。可禁用登录自启。
- 删除/移动视频不删除素材及分析记录；只有完整扫描才更新缺失状态。离线目录不造成误标，文件重现恢复可用。
- 移动到受监控目录的素材只有在原路径缺失且内容指纹唯一匹配时沿用旧记录；相同内容副本和多重匹配按新素材处理。
- 重复文件事件、补扫及进程重启不会重复入库或重复排队；分析失败沿用现有失败与重试流程。
- 设置界面能展示等待写入、分析中、成功、失败、缺失状态；安装产物可启动后台监控。
- 自动化测试覆盖目录继承/覆盖、嵌套优先级、初始扫描、稳定等待、周期补扫、离线容错、缺失恢复、唯一路径更新和托盘关闭/退出行为。

## 依赖与约束

- Windows + PySide6 桌面应用，使用现有 SQLite 素材与设置存储、入库和分析接口。
- 需添加成熟文件监控依赖并纳入 requirements、PyInstaller 和 Inno Setup。
- 遵循 ADR-0001 的工作台与素材库边界、ADR-0007 的单一权威持久化来源、ADR-0008 的便携数据目录及升级保护、ADR-0012 的现有分析失败处理。
- 数据库迁移需要可恢复；卸载、退出、目录移除均不得删除用户素材或素材记录。

## 风险与回滚

- 风险：SQLite 模式迁移、后台线程与现有分析调度竞争、网络/移动磁盘权限导致扫描不完整、登录启动出现 UI 提示、安装包托盘资源遗漏。
- 回滚：在升级协议中为新增设置/字段/表提供备份恢复；禁用登录自启、暂停监控或退出可以立即停止新扫描/入库。回退代码前按现有迁移协议恢复原数据库备份。
