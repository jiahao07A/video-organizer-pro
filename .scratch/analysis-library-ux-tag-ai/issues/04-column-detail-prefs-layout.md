# 04 — 列/详情显隐 + 列宽偏好 + 预览区布局

**What to build:** 用户可开关列表列与详情字段的显示（**列显示偏好**、**详情字段偏好**），并记住；列表列宽可拖拽、双击分隔线自适应、可重置（**列宽偏好**）；工作台与素材库同一套概念。详情**预览区**放大、底部状态栏压成一行摘要。卡片字段固定不做逐项显隐。为后续素材预览腾出可读空间。

**Blocked by:** 02 — 入库编号 + 入库轻量缩略图 + 双编号展示

**Status:** resolved

**Parent:** [spec.md](../spec.md)

## Acceptance criteria

- [ ] 可显示/隐藏列表列（含列表序号、入库编号、缩略图、文件名、分类、标签、状态等既有列概念）；偏好可持久化往返（可测）
- [ ] 可显示/隐藏详情字段（如摘要、转录）；隐藏不删数据；偏好可持久化
- [ ] 列宽拖拽后记住；双击分隔线自适应；提供重置列宽
- [ ] 工作台与素材库列/字段/列宽概念对齐
- [ ] 底部状态栏仅一行（如「素材库共 N 条」），不占大块空白
- [ ] 详情预览区明显大于底栏，布局上可容纳后续播控
- [ ] 卡片字段不做逐项显隐开关
