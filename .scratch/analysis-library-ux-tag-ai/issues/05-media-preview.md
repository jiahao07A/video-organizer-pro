# 05 — 素材预览（播控 + 定位文件）

**What to build:** 在详情**预览区**提供应用内**素材预览**：播放/暂停、进度拖动、音量、倍速；以及在资源管理器中打开所属文件夹并**定位该文件**。工作台与素材库共用同一套预览。文案与「模拟预览」区分。切换选中视频时不串播。

**Blocked by:** 04 — 列/详情显隐 + 列宽偏好 + 预览区布局

**Status:** resolved

**Parent:** [spec.md](../spec.md)

## Acceptance criteria

- [ ] 选中单条视频后，详情预览区可播放该文件
- [ ] 支持播放/暂停、进度拖动、音量调节、倍速
- [ ] 提供「在文件夹中显示」：打开所属文件夹并定位该文件
- [ ] 工作台与素材库行为一致
- [ ] 切换选中项时停止或切换播放源，避免串音
- [ ] 界面文案使用「素材预览」，不与「模拟预览」混淆
- [ ] 播控与定位以人工验收为主（非 CI 必过）
