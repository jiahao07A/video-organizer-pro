## Acceptance criteria

- [ ] 设定工作范围为测试目录后，点「开始分析」：pending 进入真实分析（非秒完成空跑）
- [ ] 分析成功后列表/详情有分类、摘要、归一后的标签；状态为已分析
- [ ] 模拟预览与应用重命名可对已分析条目执行（按既有高风险确认）
- [ ] 入库缩略图与双编号可见（若 02 已交付）
- [ ] 工作台移出范围 / 素材库取消入库语义正确且不删磁盘文件（若 03 已交付）
- [ ] 素材预览播控与「在文件夹中显示」可用（若 05 已交付）
- [ ] 待审/冷启动/近义巡检 AI 均为建议+确认，无静默写库（若 06–08 已交付）
