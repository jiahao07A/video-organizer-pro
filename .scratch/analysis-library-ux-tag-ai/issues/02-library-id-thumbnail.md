# 02 — 入库编号 + 入库轻量缩略图 + 双编号展示

**What to build:** 视频首次入库获得稳定**入库编号**，并轻量抽帧生成**缩略图**（不依赖是否已分析）；分析成功可覆盖更优帧。列表与卡片同时展示**列表序号**（当前筛选/排序后 1…n）与入库编号；缩略图在列表/卡片/详情能正常加载。用户未分析也能辨认画面、用两套号定位素材。

**Blocked by:** None — can start immediately（可与 01、03 并行）

**Status:** resolved

**Parent:** [spec.md](../spec.md)

## Acceptance criteria

- [ ] 首次入库分配稳定入库编号；同一文件再次扫盘编号不变（可单测）
- [ ] 入库路径生成轻量缩略图并写入记录；缺失时占位不崩溃
- [ ] 分析成功可更新缩略图
- [ ] 列表展示列表序号与入库编号，表头/文案可区分
- [ ] 列表序号随筛选/排序变化，不入库
- [ ] 卡片固定信息含：列表序号、入库编号、文件名、分类、状态、标签约 2～3 个（+N）；缩略图正确
- [ ] 工作台与素材库行为一致
