# 03 — 移出工作范围 / 取消入库

**What to build:** 工作台「删除」= **移出工作范围**（库记录与磁盘文件保留，素材库仍可见）；素材库「删除」= **取消入库**（去掉库内管理记录，默认不删磁盘视频；工作台也不再显示该条）。两页提供显眼删除按钮与确认文案（使用 CONTEXT 产品词）。用户能安全管理范围与库存而不误删原片。

**Blocked by:** None — can start immediately（可与 01、02 并行）

**Status:** resolved

**Parent:** [spec.md](../spec.md) · ADR-0001

## Acceptance criteria

- [ ] 工作台删除：目标视频不再属于工作范围；素材库仍能查到记录；源文件仍在磁盘（可测）
- [ ] 素材库删除：库中无该记录；工作台列表也不再显示；源文件仍在磁盘（可测）
- [ ] 两页工具栏有显眼删除入口（不仅右键）
- [ ] 确认对话框文案区分「移出工作范围」与「取消入库」，不暗示删磁盘文件
- [ ] 本票不实现「删除磁盘文件」
