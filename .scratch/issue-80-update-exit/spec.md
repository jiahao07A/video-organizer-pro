# Issue #80：更新交接必须退出旧进程

GitHub Issue: #80
Branch: fix/80-update-exit

## 背景和目标

托盘模式中，关闭最后窗口不会退出 Qt 事件循环。更新启动安装器后若只关闭窗口，旧应用仍持有安装互斥量；准备状态遗留也会阻止用户从托盘退出。修复后，安装交接能够请求应用正常退出，释放运行互斥量，并由安装器继续工作。

## 范围

范围内：新增明确的安装交接状态；统一应用关闭并显式请求 Qt 退出；在退出受阻时允许安全重试；加入独立子进程回归测试及脱敏事件记录。

范围外：不强制结束进程，不更改安装器签名/摘要校验、数据迁移或升级成功判定，不将安装器启动视为升级成功。

## 验收标准

- 托盘模式下更新交接会结束 Qt 事件循环，而不是只隐藏窗口。
- 一次关闭受阻后用户可以重试退出，安装器不会被重复启动。
- 启动安装器失败时保留当前进程、缓存和数据备份，并恢复可操作状态。
- 更新相关回归测试通过；新版首次启动仍执行既有素材库核对。

## 风险与验证

用子进程运行真实 Qt 事件循环，以安装器替身避免实际安装。另运行更新状态、签名、镜像和 GUI 更新测试。在本机不能替代 Windows 安装版端到端验收；远程更新只可在另行授权后进行。
