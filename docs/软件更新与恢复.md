# 软件更新与恢复

## 日常更新

安装版打开“系统设置 → 软件更新”。默认每天检查一次正式版本，不会自动下载。
确认更新说明后下载；完成后点击“安装并重启”。先结束后台任务，保存设置，应用会备份管理数据。
安装器可能提示关闭其他实例，请自行正常关闭，不要强行结束分析或文件操作。
安装完成默认启动程序；只有新版成功打开原素材库，才报告更新完成。

测试版本需要主动勾选“接收测试版本”。关闭此选项不会自动降级当前程序。
若 GitHub 无法访问，可在可联网设备从官方 Release 下载安装包、update.json 和 update.json.sig，
将三者放在同一目录，在更新页选择“导入离线更新包”，并选择 update.json。
修改过的清单、签名或安装包不能通过验证；不要使用来历不明的下载代理。

## 从旧版接入

首个支持更新机制的版本需要手动安装一次。后续才可以应用内更新。
ZIP 旧版先退出并备份整个管理数据目录，再安装新版。首次启动时选择原管理数据目录，
不要通过覆盖数据库或搬动原始视频来“迁移”。安装目录中的 data 和用户自选数据目录都应保留。

## 更新未完成

关闭安装向导或安装失败后，原数据和更新前快照会保留。正常启动旧程序可重新下载或安装。
更新页“更新失败与恢复指引”显示更新前备份位置；更新状态位于
`%LOCALAPPDATA%\VideoOrganizerPro\<安装路径标识>\updates\session.json`。
其中记录原安装位置、原数据目录、备份位置及上一个版本号；不包含 API Key。

安装过程中断电可能损坏程序文件，不能承诺原程序仍能启动。重新运行同版本官方安装包修复程序，
使用原安装位置；不要先卸载或删除数据。再启动，程序会核对原目录，不应出现一个新的空素材库。

## 恢复数据或旧版本

恢复会失去更新后新增的记录，必须先保留当前数据，并由你确认。
能正常启动时，使用“系统设置 → 管理数据备份/恢复”选择更新前快照；现有恢复服务会先备份当前数据。
恢复后按提示重启，再从官方 Releases 获取对应旧安装版本。旧程序禁止直接写入更高版本数据库。

若程序完全无法启动：

1. 退出所有实例，复制保留完整的当前管理数据目录，包含数据库旁的 `-wal`、`-shm` 文件及配置。
2. 从更新记录找到 `backup_path`。保留原快照，复制一份到新的空恢复目录，不覆盖原数据。
3. 快照中的 `database.sqlite` 复制为 `video_organizer.db`，并复制 `settings.json`、`tag_config.json`
   （仅复制快照清单标记存在的文件）。快照不包含原始视频；视频应保留原路径。
4. 安装对应的官方旧版本，启动时通过数据目录选择入口选择恢复目录。
   若启动核对拦截，可先复制留存 session.json，再将该**单个文件**改名为 session.saved.json，
   并将程序旁的 `.video-organizer-data.json` 指向恢复目录；若使用用户目录的备用定位文件也要同步。
   不熟悉定位文件时，保留现场并请维护者协助，禁止删除数据库尝试解决。
5. 验证素材数量、标签和设置后再继续使用。保留更新前和恢复前备份。

## 维护者发布

安装更新依赖由 `requirements-update.txt` 固定，先安装这些依赖。
版本唯一来源是 `core/app_version.py`。先完成测试及用户确认，再提交和评审；公开发布需要明确授权。
使用新的 PyInstaller workpath/distpath；不要运行会清理默认目录的 build.py。
安装器使用 `tools/build_installer.py --iscc <ISCC.exe> --dist <目录包父目录> --output <全新输出目录>`。
Inno Setup 简体中文语言文件已固定在仓库 installer/languages 中。

签名私钥保存在仓库外 `%LOCALAPPDATA%\VideoOrganizerPro\release-signing\update-ed25519.pem`，
已限制当前 Windows 用户访问；请另做安全离线备份，不提交或上传到 Release。
客户端仅包含对应公钥。丢失私钥后不能给既有客户端发布可信更新，需手动安装携带新公钥的版本。
如需轮换，先发布同时信任新旧公钥的过渡版本，再改用新私钥；保留旧客户端兼容路径。

运行 `tools/update_release.py manifest --installer <exe> --key <私钥路径> --output <全新目录> --notes-file <中文说明.md> --tag <v版本号>`。
工具验证私钥对应客户端公钥、标签与版本一致，生成 update.json、update.json.sig 和摘要文件。
先建立 Draft Release，上传安装包及全部清单资产，下载回验签与 SHA-256 校验，完成隔离安装冒烟后才公开。
不复用标签和资产，不把设置、日志、数据库、备份或真实视频打进安装包。
Ed25519 清单签名保障更新来源；它不等同于 Windows Authenticode 签名，不消除 SmartScreen 提示。
