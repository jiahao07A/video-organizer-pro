# Video Organizer Pro 0.0.1-rc11（预发布）

这是候选测试版本，不是正式稳定版。应用内更新需开启“接收测试版本”。

## 设置中心重设计

- 按工作职责组织九个页面，明确每项配置的影响范围与生效时机；搜索可以展开对应卡片并聚焦控件。
- 分开管理AI连接和模型分配，显示任务实际使用的连接、模型与继承来源；连接测试只刷新候选，不替用户选择模型。
- 编辑停止800ms后自动保存，Key、URL和Prompt失焦立即提交；设置文件与标签配置分别反馈结果，失败时保留编辑内容并允许重试。
- 区分全局监控默认值和单目录覆盖，支持逐项继承；卡片恢复及全部恢复保留连接凭据、监控目录身份、数据库、素材和数据位置。

## 配置安全与修复

- 兼容旧设置和标签配置、UTF-8 BOM与明确的旧类型；保留扩展字段、模型动态继承和监控覆盖。
- 升级前保存逐字节原始备份，验证成功后原子写入；损坏或来自更高版本的配置会拒绝覆盖。
- 修复维护操作与监控写入竞态、规则重配意外恢复暂停、连接改名及候选刷新问题。
- 包含更新安装交接退出、失败恢复和分析性能观测的既有修复。

## 安装与更新

关闭运行中的应用，备份管理数据目录，再运行 `VideoOrganizer-v0.0.1-rc11-setup-win-x64.exe`；已有安装请选择原安装位置。不要删除数据库或移动原始视频来升级。

更新资产提供Ed25519签名清单及SHA256。升级原始配置快照位于管理数据目录的 `backups/config-upgrades/`，可能包含API Key，应按私人配置保护。

安装器未进行Windows Authenticode代码签名，Windows可能显示SmartScreen提示；更新清单签名与Windows代码签名是两件不同的事。正式生产数据覆盖安装及真实供应商付费请求不属于本轮隔离验证范围。

已知既有行为：主窗口恢复列偏好时可能等值保存settings.json，导致修改时间变化；这不表示配置再次升级或内容被修改。
