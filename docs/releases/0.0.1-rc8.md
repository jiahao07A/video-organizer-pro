# 0.0.1-rc8

本次为测试版本。

## 新增与优化

- 新增独立的素材监控工作区，可管理多个目录、查看批次与阶段进度、暂停恢复、人工核对、接管及显式导出。
- 支持全局默认与单任务覆盖，可设置首次扫描、过滤排除、文件稳定等待、并发、重试、命名和 XMP；批次保存实际配置，中途修改设置影响后续批次。
- 新增全库完整内容指纹去重。不同路径保留独立入库编号，最早编号为原记录，副本跳过内容分析、命名、XMP 和内容导出；已有历史成果保留。
- 素材库新增来源、任务、批次、核对状态和重复身份筛选；列表、卡片与详情显示管理信息。
- 支持托盘后台监控与可选 Windows 登录启动；手动任务在后台批次边界优先。

## 修复

- 暂停恢复时区分已派发与未派发素材，保留队列；请求结果未知时进入人工核对，避免自动重复付费调用。
- 修复快速暂停恢复、等待共享队列及人工接管期间的阶段覆盖问题。
- 修复后台操作中切换选择或发起第二次操作导致的素材快照错配。
- 修复暂时不可读文件阻塞整批，以及恢复可读后周期补扫被历史基线跳过的问题。
- 修复程序主动写入内嵌元数据后的内容版本衔接，以及等待稳定期间过滤设置变更未重新校验的问题。

## 升级与回退

管理数据库升级至版本 5。首次启动请按提示确认备份与升级；原始视频不随管理数据备份复制。回退 RC7 或更早版本前，应恢复升级前管理数据备份，不能直接用旧版写入新版数据库。

若使用应用内更新，请启用“接收测试版本”。离线更新请同时下载安装包、`update.json` 与 `update.json.sig`，通过更新页导入清单。

本版本仍需结合真实素材与服务进行人工验收；Windows 重新登录自启、真实显示器高 DPI 及真实付费接口不包含在隔离自动验证内。
