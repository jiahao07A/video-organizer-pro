# 0.0.1-rc9

本次为测试版本。

## 修复

- 校验视频分析响应、持久缓存和恢复上下文，避免模型返回的失败说明被误记为成功摘要、写入素材库或用于文件名。
- 明确无效分析响应进入现有有界重试和失败分类；不写入待审标签、XMP 或媒体元数据，并保留强制重新分析前已有的有效成果。
- 重命名预览、批量重命名和素材监控会阻止使用明确无效的旧分析摘要；逐项报告失败，其他素材继续处理。
- 修复隔离安装冒烟对托盘关闭行为的误判，通过应用正式退出入口测试正常退出；普通关闭窗口时最小化到托盘的行为保持不变。

## 升级与回退

本版本不改变数据库结构。历史素材库不会在启动时自动批量修订或重新分析。发现旧失败摘要时，可强制重新分析或人工修正摘要后再预览重命名。

RC8 及更早版本可能把无效摘要保存为成功结果；安装前请备份管理数据。此候选版本仍需使用少量测试素材进行人工验收。明确失败检测不能识别全部模型幻觉；供应商真实视觉能力及真实付费 API 不在隔离冒烟测试范围内。

发现问题时保留当前管理数据与备份，不复用或移动 `v0.0.1-rc9` 标签；后续修复使用新的候选版本。
