# Video Organizer Pro 0.0.1-rc12（预发布）

本次候选版集中修复全项目审查发现的媒体安全、交互、接口和性能问题。应用内接收此版本需开启“接收测试版本”。

## 媒体与数据安全

- CLI 分析和改名严格限定本次输入，空目录、初始化或分析失败返回失败状态，避免改动范围外素材。
- 内嵌元数据写入保留原容器、全部媒体流和章节，前后校验后才替换；处理中源文件变化时拒绝保存过期结果。
- 文件名清理覆盖 Windows 控制字符，非 ASCII 路径的大小写匹配保持一致。
- 侧栏备份统一检查后台任务并保存待提交设置；卸载按安装清单处理，保留安装目录内非清单数据。

## 界面与导出

- 修复设置页模型刷新、快捷主题保存、监控高级设置返回导航和详情保存后筛选结果不刷新。
- 小窗口的详情和播放控件可换行、滚动，支持真实点击播放、暂停、倍速和编辑保存。
- 工作台增加 JSON/CSV 主动导出，按选中或当前筛选范围输出；保护配置、定位器等管理路径，空结果不覆盖文件。
- ALE 遵循配置列顺序并清理破坏行列的控制字符；FCPXML 被门禁拒绝时不再误报成功。
- 损坏的更新时间会重置，健康更新偏好继续保留。

## 接口、性能与测试

- 修复音频节流后转录请求丢失，取消后不会补发；模型刷新实际经过按钮、后台线程、SDK 和 HTTP 验证。
- 大库首页使用轻量编号分页；本机20万条合成记录首屏由约1359毫秒降至约4–7毫秒。范围筛选仍有扫描成本，这些数据不代表所有设备表现。
- 监控补扫复用数据库连接，减少相邻发现/资格检查的重复文件哈希，后续安全校验继续执行。
- 强化指标、基准、密钥持久化和中文路径测试，使用故障注入识别测试假绿。

## 验证与已知边界

审查修复后的业务源码完成1305项测试，0失败、0跳过，包含9项压力测试。Windows 11 x64 build 26200、150% DPI 下完成真实桌面操作和七种视频格式的实际分析、元数据及预览验证。详细证据与限定条件见 [完整审查报告](../reviews/2026-11-21-project-review.md)。

Windows 10 尚未取得实机运行证据，不能宣称已通过。依赖与安装器最低要求为 Windows 10 1809 / build 17763、x64。付费外部 AI 服务、Final Cut Pro / DaVinci Resolve 实际导入、连续数天运行及真实卸载尚未验收；公网更新一次成功、后续复查出现 HTTP 403。现有测试仍有81个 Qt 弃用警告。

## 安装与更新

关闭运行中的应用，备份管理数据目录，再运行 `VideoOrganizer-v0.0.1-rc12-setup-win-x64.exe`；升级请选择原安装位置。备份管理数据不等于备份原始视频。

提供 Ed25519 签名更新清单、签名文件与 SHA-256 摘要。安装器未做 Windows Authenticode 代码签名，Windows 可能显示 SmartScreen 提示。

本版本以 GitHub Pre-release 发布，清单渠道为 `preview`，不替代正式 Latest。维护者会在公开前完成合并源码重建、隔离双次安装与数据保留检查，以及草稿资产下载后的验签和摘要核对。
