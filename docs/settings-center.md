# 设置中心职责与验收说明

本轮设置中心按工作区、AI 工作流、素材处理、输出与维护组织为九页。导航、搜索和设置卡片共享 `gui/models/settings_catalog.py` 中的职责目录。具体配置路径可查同目录中的 `config_path`、`storage_target`、`scope` 和 `effective_when`。

## 使用路径

| 想完成的工作 | 页面与交互 |
| --- | --- |
| 调整外观、素材显示与启动范围 | 界面与工作区：外观、素材显示、布局、记住范围各自分卡 |
| 新增或更换 API 地址和密钥 | AI 连接：最多五个档案；密钥默认隐藏；设为默认回退；测试只刷新候选 |
| 为 AI 功能选择供应商和模型 | AI 模型分配：任务卡显示实际连接、模型和继承来源；连接默认模型在页面下方 |
| 调整分析与标签 AI 指令 | 提示词与标签：角色提示、标签组引导词、标签库模板和只读预览 |
| 分清三个并发参数 | 视频分析：整条分析流程、前置图片准备、新素材入库分别分卡；入库项默认折叠 |
| 控制失败请求及费用 | 失败处理：普通重试和 HTTP 400 独立卡片，各自恢复默认 |
| 修改未覆盖任务的监控规则 | 监控默认值：扫描稳定、文件筛选、自动处理、命名/XMP、费用高级项、通知分组 |
| 修改某一目录的监控规则 | 素材监控中选择目录后打开高级设置；每项可继承全局；Windows 登录启动只在全局页 |
| 设置文件名与导出格式 | 命名与导出：唯一可编辑的命名模板、XMP 写入/格式、ALE 列 |
| 搬迁、备份、恢复及更新 | 数据与维护：必须明确点击触发；恢复管理数据和目录切换后需重新启动 |

模型按既有路由规则解析：六类常规 AI 任务之外保留已有的错误诊断槽，其位于默认折叠的诊断分组，不修改其业务规则。模型候选获取和连接测试不会选择模型或切换默认连接。

## 保存与恢复边界

停止输入 800ms 后自动保存；文本字段失焦立即提交。设置文件和标签配置分别报告状态，一方失败不阻止另一方写入，重试只重写未成功的目标。错误文案不显示原始异常或密钥，失败时保留编辑内容。普通设置不会重启素材监控；监控规则变化时保留暂停状态。

连接测试成功会刷新已打开选择器的候选，保留手填或已选模型；连接改名保存后同步更新选择器名称。备份与恢复前停止监控扫描，并检查运行中或排队中的分析。取消或失败时恢复原监控运行状态；恢复成功后保持停止，直至退出重启。

设置文件继续承载普通偏好、连接档案、模型路由、重试、监控以及既有标签库 AI 模板。全局角色提示、标签组提示和 XMP/ALE 导出格式通过标签配置写入。既有配置键保持兼容；配置自动升级增加独立格式版本与升级前原始快照，详见 [配置自动升级与恢复](configuration-upgrades.md)。

每张卡片的恢复按钮只处理本卡片的字段。全部恢复保留连接档案身份与密钥、监控目录身份/路径/启用状态、数据位置、数据库和素材；恢复模型分配和供应商默认模型，监控任务覆盖清为继承。全局监控卡片的局部恢复保留任务专属覆盖。备份恢复是单独的显式操作，不属于偏好默认值恢复。

## 自动化验收

测试位于 `tests/test_settings_catalog.py`，并更新原有设置、HTTP 400、搜索和窗口布局回归：

- 分组导航、唯一编辑入口、目录元数据与控件归属。
- 800ms 防抖，包括开启记住工作范围时；Key、URL、Prompt 失焦保存。
- 两个存储目标独立失败、重试、敏感信息脱敏、编辑内容保留。
- 模型候选不改变路由，路由保存后重建客户端，普通偏好不重建。
- 连接测试刷新现有候选但不改模型，连接改名同步标签而不重载编辑表单。
- 管理数据维护期间停止监控；拒绝分析中或排队中的任务，覆盖取消、失败、成功与停扫描后复查分支。
- 卡片恢复范围、全部恢复保留项、监控任务继承和缺失任务保护。
- HTTP 400 恢复后继承显示同步；普通设置不恢复已暂停监控。
- 新服务实例重新读取配置，核对连接、路由、提示词与导出格式。
- 1280×720、1024×768 离屏布局：右侧滚动、无横向溢出、底部入口可达、搜索展开/聚焦、焦点链。
