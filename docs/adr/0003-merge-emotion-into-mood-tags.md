# 情绪并入氛围标签组（取消独立情绪字段）

Status: accepted

标签系统以库内检索为主、导出为次，并采用半封闭选词与精瘦分析词表。独立「情绪」字段与氛围标签组语义重叠，会让 AI 重复填两套近义词，也让高级筛选出现双入口。决定：**分析结果不再包含独立情绪字段**；情感/基调统一由**氛围**封闭标签组承载（单选、仅从库选）。高级筛选中的「情绪」维取消，改为按氛围标签（或标签筛选）收窄。导出与重命名中的 `{emotion}` 类变量下线，相关语义以氛围标签关键字代替。

相对 ADR-0002：该 ADR 在瘦身时仍保留情绪字段；本决策在「标签深度优化」中将其并入氛围组，**在情绪维度上 partial-supersede ADR-0002**（分类/摘要/标签保留结论不变；构图/星级等硬删结论不变）。

**Considered options:** 保留情绪与氛围并划清边界（否决：用户选择合并以降低复杂度）；去掉氛围只留情绪（否决：损失风格检索与组结构一致性）；维持重叠不区分（否决：近义重复、提示词负担）。

**Consequences:** 旧数据中的 emotion 按硬删/忽略策略处理（与已删分析字段一致）；筛选 UI、导出 ALE 列、文件名变量需同步去掉情绪；氛围组词表需覆盖原「情绪」高频词（如开心、紧张），并与纯视觉风格词共存于同一封闭小词表。
