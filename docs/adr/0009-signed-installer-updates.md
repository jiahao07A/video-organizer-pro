# 签名清单驱动的安装版更新

Status: accepted
Date: 2026-11-07
Issue: #51

## 决定

复用 Inno Setup 完整安装包，不实现文件覆盖器。GitHub Releases 提供安装包、update.json 和 Ed25519 独立签名。
客户端使用固定仓库、限定 HTTPS 域名、内置公钥、大小和 SHA-256 校验；拒绝无可信清单的历史版本。
版本排序使用 packaging；正式渠道同时检查发布标记和版本预发布属性。

应用启动后延迟检查，不自动下载；安装前冻结界面、阻止后台任务、保存设置，复用一致性数据快照。
安装器用 AppMutex 识别运行实例，并由 Inno Setup 的 CloseApplications 发送正常关闭请求；不强制结束进程。用户确认后安装器继续，应用拒绝关闭时仍可取消。保持安装位置、data 和定位记录。
更新成功必须经过新版启动和原素材库核对，安装器启动不能作为成功证据。

## 后果

补充 packaging、cryptography、psutil 固定版本依赖。签名私钥在仓库外由维护者保存；公钥随客户端发布。
首个支持更新的版本需手动安装。便携版仅提供迁移指引。更新失败保留快照，恢复由用户确认。
遵守 ADR-0007/0008，不改变数据权威来源和受控升级约定。Windows 代码签名与清单签名分别处理；
清单签名不代表安装器获得 Windows 可信发布者证书。
