# 标签归一：硬过滤 + 待审词（禁止模糊贴词）

Status: accepted

半封闭选词下，模型仍可能对封闭组输出库外词或别名。落库前统一做**标签归一**：别名映射为标准词；封闭组中仍无法对应标准词的项**丢弃**，并记入**待审词**供人工批准为新标准词、挂为别名或丢弃；建议组库外词可挂在该视频上但不自动入库。**禁止**将库外词自动模糊匹配到「最近」标准词（错贴成本高于漏标）。

**Considered options:** 只丢弃不记待审（否决：词表难随真实素材进化）；模糊近邻贴词（否决：准确度风险）；信任模型原文（否决：半封闭失效）。

**Consequences:** 需提供待审词的产品入口；封闭组偶发空缺属预期，细节靠摘要与建议组；分析候选与导出主关键字仍只使用标准词。
