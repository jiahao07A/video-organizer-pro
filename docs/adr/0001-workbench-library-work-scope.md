# 工作台、素材库与工作范围分工

Status: accepted

原先单一「工作台」同时承担总库存浏览与当前任务处理，容易在未勾选时对全库执行重命名等高风险操作。现拆为：**素材库**呈现全部已入库视频素材（检索、同款高级筛选、勾选后累加进工作范围）；**工作台**只呈现并处理**工作范围**（路径集合：多文件/多文件夹；浏览默认替换，累加追加）。设定工作范围时扫盘入库（含未分析）。分析、模拟整理、重命名、导出等默认只作用于工作范围。启动默认空范围并提示；设置可开启「记住上次工作范围」。

**Considered options:** 继续单页全库显示（否决：与「只处理当前范围」冲突）；素材库累加再弹路径对话框（否决：与「从库存勾选」心智不一致）。
