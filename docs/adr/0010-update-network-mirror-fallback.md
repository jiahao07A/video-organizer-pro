# 更新网络失败时使用固定镜像传输

Status: accepted
Date: 2026-11-07
Issue: #55

## 背景与取舍

ADR-0009 将更新网络限定为 GitHub 官方域名。用户要求国内网络兜底；仅提供网页入口无法在 GitHub 不可达时完成检查及下载，而允许任意代理地址会扩大不必要的请求范围。

## 决定

补充 ADR-0009 的网络来源规则：默认优先访问 GitHub；仅在连接错误、超时、HTTP 429、明确的限流 403 或 500/502/503/504 时，每个请求最多再试一次固定 HTTPS 镜像 `gh-proxy.org`。
镜像只接受固定仓库公开发布列表及资产的官方 URL，禁止嵌套代理、其他仓库或任意外部 URL；重定向同样验证允许目标。每个新请求仍先官方，不长期锁定镜像。

镜像只承担传输角色，不能作为更新来源的信任证明。内置 Ed25519 公钥、原始清单签名、安装包大小及 SHA-256 验证保持不变；来源不符、取消、TLS 证书失败、磁盘错误、响应超限或签名/摘要失败均不触发网络兜底。
官方部分下载失败后截断该单个 part 文件重新下载，不拼接两源内容。用户能看到使用镜像；两源均失败时显示可重试错误。

## 后果

第三方镜像可能不可用、滞后或拒绝访问；客户端不能承诺新版本绝对最新，但镜像不能让未通过签名和摘要的安装包执行。
仅向镜像发送公开更新 URL、通用 User-Agent/Accept，不带 AI API Key、管理数据、素材或用户配置。回退到仅 GitHub 不影响数据格式、备份和安装器。
