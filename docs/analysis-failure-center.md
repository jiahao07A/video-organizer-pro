# 分析失败处理中心

工作台、素材库和素材详情的“分析失败处理”入口汇总自动重试后仍失败的分析任务。窗口默认继承当前操作范围；有选中时使用选中项，否则使用当前筛选结果的全部分页。点击“全部历史”可查看已恢复记录。

失败原因由本地规则分类，包含鉴权/权限、余额/配额、限流、网络/超时、服务不可用、模型或接口不兼容、参数/输入限制、内容拒绝、响应为空/解析失败、文件读取/解码、结果保存和未知错误。原因和恢复状态是两个独立字段。400内容拒绝不会被当作素材损坏。

窗口可按原因、阶段、恢复状态、HTTP状态码、供应商ID、模型、失败时间、尝试次数、关键词、曾遇到400及保留旧结果组合筛选。修改高级条件后点击刷新。列表每页100条，分类统计使用同一数据库查询；未加载分页也会纳入批量目标。可明确切换到全部素材库。双击行查看错误和历史详情。

手动重试沿用原有“按有效策略”“仅主API”“指定API”模式，并可为本次设置并发和请求间隔。开始前会跳过不存在或不可读取的文件并显示请求预览；设置默认仅本次生效。成功结果和标签副作用仍按原子事务保存，重新分析失败不会覆盖既有成功结果。取消不会继续提交新请求，结束后可按本轮仍失败项继续处理。

“AI诊断相同错误组”是主动操作。相同阶段、连接、状态码和错误特征只诊断一次；发送内容经过脱敏，不包含密钥、完整路径、视频、音频或请求体。诊断结果会按错误特征和诊断模型缓存，用户确认后才能将支持的节奏建议填入重试设置，不会自动开始分析。

数据库升级沿用启动确认和升级前备份。程序重启只将进行中的恢复标记为中断，不自动请求API。完整历史仍保存在SQLite中。

当前数据库版本为3，旧普通失败仅按已有错误补录；缺失的请求次数和供应商显示为空。指定API模式分别填写视频主分析与音频转录连接。重试预览展示可执行数、跳过数、模式、连接及请求上限，确认后才开始。运行中关闭窗口会先取消，等待已发出的请求结束后可关闭。

列表与操作使用同一份已应用的筛选条件；修改关键词或高级条件后点击刷新或按回车，分页不会提前应用尚未刷新的条件。选择“仅显示本轮仍失败项”时，暂时停用其他筛选条件，关闭该选项后可恢复普通筛选。

手动轮次在首个请求前取启用阶段预算的最小值，预览确认后冻结每条素材上限；后续增大设置不会提高本轮请求额度。结束后显示成功、仍失败、跳过及取消数量，其中取消与仍失败分开计算。普通重新分析首次失败也保留原成功状态和结果。

诊断默认串行，每组最多一次请求；失败诊断不写入成功缓存。可取消后续组的诊断。“应用建议到重试设置”可填入经过校验的分阶段连接、尝试次数、并发和间隔；仍需点击“开始重试”确认。音频未启用时，音频连接建议会提示无法应用，并保留诊断窗口。

点击“更改供应商和模型”可切换到指定API模式，初始带入当前视频主分析连接和音频连接。两阶段可分别选择供应商、手填模型及设置尝试上限；次数选择“沿用策略”时使用已有配置。音频未启用时不能编辑音频连接。重试预览会列出各阶段有序连接链、每个连接的尝试上限和所有阶段共用的请求预算，实际请求总数受共用预算限制。

手动设置中的“单视频本轮请求总上限”从首次请求开始计数，包含兼容重发和音频请求。输入模型后按回车只完成编辑；点击“开始重试”或将键盘焦点移动到该按钮后按回车，才进入预览。高级筛选在独立区域内滚动，Tab切换字段时会跟随焦点显示，底部操作按钮保持可见。

操作范围使用明确的下拉选项：选中项或全部筛选结果，并显示数量。选中仅限当前页，翻页或刷新会清空，但不会自动扩大操作范围。高级筛选默认折叠，单选后可点击“查看详情”，单元格悬停可阅读完整内容。失败数量减少时自动回到有效页码。

普通分析结束存在失败时，结束消息提供“查看本次失败项”；只有点击才打开处理窗口，范围限定为本次失败素材。诊断按组展示阶段、连接、HTTP、原因、依据、确定程度和建议，应用按钮位于对应组内。取消后按钮显示正在取消并停用，等待当前请求完成；诊断结束显示成功、失败和未执行/取消组数。

时间筛选明确使用UTC。只填结束日期时包含当天全部记录；填写带时区的ISO时间时，按同一实际时刻比较。日期无效或开始晚于结束时提示修正，并保留上次已应用的列表和操作范围。

诊断必须包含非空原因、依据及建议列表，空对象和缺少必要字段的响应计为失败，不缓存；已有无效缓存也不会复用。结果窗口提供“重新诊断本次目标（忽略缓存）”和“仅重试诊断失败组”，重新请求前仍需确认预览。应用无效建议会在原结果窗口提示，保留其他组的诊断内容。

恢复状态使用“已恢复”等通用文案，是否曾遇到400单独展示。详情中可阅读本地分类、依据和处理建议，选中历史行后可在下方滚动阅读和复制全文。列表统计与任务状态分开显示，刷新、翻页和筛选不会覆盖运行或取消提示。

列表为空时，普通筛选会提示调整筛选或范围；“仅显示本轮仍失败项”的空列表只表示该范围没有匹配记录，成功、跳过及取消数量以本轮结果为准。清除视频专属策略时，保存失败会显示原因并保留当前编辑内容，可再次尝试；保存成功后恢复继承并明确提示尚未发起重试。

视频主分析还会校验结果本身。缺少有效分类或摘要、标签类型错误、明确的失败标志，以及“抽帧失败，未能获取视频画面内容”等模型自述失败，均计为响应问题，沿用现有重试上限；不会保存为成功、写入待审标签或用于文件名。这里的“抽帧失败”是模型输出，不能据此判定本地视频损坏。

读取分析缓存和恢复上下文时使用同一校验；单条无效缓存被丢弃，重新请求有效结果。旧成功记录不会在启动时被批量改写，也不会自动发起请求。若旧摘要已经包含明确的分析失败说明，重命名预览会显示拦截原因，监控任务会进入待核对。可先选择这些素材执行“强制重新分析”，或人工修正摘要后重新预览；只使用原名、日期的自定义重命名仍可执行。不要直接批量应用包含错误摘要的命名规则。
