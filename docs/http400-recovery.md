# 视频分析400恢复使用说明

## 设置

进入“系统设置 → 常规 → 分析失败处理 → HTTP 400 重试与备用 API”。也可在顶部搜索“400”或“备用”直接定位。该区域直接在主页面编辑，使用底部“保存所有设置”统一保存。供应商档案沿用“AI 引擎”页的配置。

备用 API 先选择供应商，再点击模型框旁的“获取”，即可搜索并选择该连接的模型；也可直接填写自定义模型名。获取列表不会自动替换当前值。详细操作见[模型列表与选择](./模型列表与选择.md)。

“设置范围”默认选择“所有分析任务（默认设置）”，常用项直接可编辑。需要不同规则时，可切换到“视频主分析（单独设置）”或“音频转录（单独设置）”。视频主分析一次生成分类、标签和摘要；音频转录规则只在启用转录时生效，备用模型应支持音频转录。

表单按“自动重试”“备用 API”分组；等待方式、并发和排除规则默认收起在“高级选项”。高级参数折叠后仍会保留并保存。浮动幅度按百分比显示，例如20%。普通错误重试也在同一“分析失败处理”区域，HTTP 400不叠加普通错误的重试次数。

任务、视频或本次覆盖中的“沿用上级”表示继承，取消勾选后可独立设置。取消备用列表的继承并清空列表，表示明确不使用备用 API。可以添加多个备用连接、上下调整顺序、临时禁用某一项、指定每项总尝试次数；“默认”表示使用该任务的备用默认次数。

默认主API额外尝试2次，等待2秒起步、指数增加、最多30秒并附20%随机浮动；恢复预算8次、集中兜底并发2。预算是首次400之后的实际请求总上限，包含参数兼容重发；不会与普通三层重试相乘。自动恢复排除规则中，同一行的已填条件须全部满足，不同行满足任一行就排除。规则仅影响自动恢复，手动恢复仍可主动执行。

预览显示请求上限及可能接收素材的备用 API，展开“查看生效值与来源”可核对每个字段。修改范围不会丢失其他范围的未保存编辑；点击“保存所有设置”后统一验证和持久化，下一轮分析生效。手动重试与视频专属策略仍使用各自的确认弹窗，共用同一分组表单。

## 查看与手动重试

工作台与素材库的状态列显示400标记；已成功素材重新分析失败会保留原结果，并显示“重新分析失败·400”。详情区“400恢复详情与历史”可查看错误、次数、时间及供应商/模型；成功后保留“曾遇到400，已恢复”。HTTP 400本身不代表视频文件损坏。

高级筛选可选“当前400未恢复”“重试耗尽”“曾遇到400”。有选中时，“重试400失败项”仅处理选中项；没有选中时处理全部筛选结果中的未恢复项，包括尚未加载的分页。

手动弹窗提供按有效策略、仅主API、指定兜底三种模式。每次开启新的有限恢复轮次，跳过旧缓存。临时覆盖默认只对本次生效；勾选保存可合并到视频专属策略。清除专属策略需单独确认，清除后恢复继承。多视频预览以第一条为例，其余视频未覆盖字段仍各自继承。

在恢复详情中点击专属策略设置，可单独保存该视频的覆盖配置，不会立即发送请求；已恢复的视频也可预先设置下一轮使用的策略。

等待期间可取消；正在进行的请求可能需要返回或超时后才能结束。已成功结果保留。退出后再次启动不会自动发送请求，未完成记录标记为中断，由用户手动恢复。

## 人工验收清单

- [ ] 在临时数据目录完成升级确认，检查已有视频的分类、标签、摘要没有丢失。
- [ ] 保存全局策略和任务覆盖，关闭重开设置，验证继承、false及空列表保留。
- [ ] 配置主API失败、兜底可用的测试环境，检查标记变化、集中兜底阶段及最终成功供应商。
- [ ] 分别以三种模式重试单条和多条，确认“无选中”使用完整筛选结果。
- [ ] 原成功素材重新分析失败后仍可查看旧结果；恢复成功后清除当前错误并保留历史。
- [ ] 等待时取消；关闭重开后没有自动请求，历史与专属策略仍在。

自动测试使用模拟API和临时数据库，不代表真实供应商、真实素材或安装包已完成人工验收。
