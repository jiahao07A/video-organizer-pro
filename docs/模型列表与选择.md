# 获取模型并选择填入

在“系统设置 → AI 引擎”添加供应商，填写 API Key 和 Base URL。模型输入框旁点击“获取模型”，即可从该连接获取候选模型；Key 和地址尚未保存时，也可以先获取列表。

列表获取成功后，展开下拉框选择模型，或输入关键词搜索；同一连接的其他模型框会共享候选，不必重复获取。需要更新列表时点击“刷新列表”。获取列表不会自动选择、覆盖正在输入的模型，也不会自动保存配置。

始终可以直接手动输入自定义模型名，包括供应商列表中未展示的模型。空白路由仍沿用原来的默认回退规则。选好默认模型和任务模型后，点击“保存所有设置”。

这些入口共用同一种选择方式：

- AI 引擎中的供应商默认模型与任务模型路由。
- 分析失败处理中的备用 API 模型；在该行先选择供应商，再点击“获取”。
- 视频专属恢复策略与手动重试中的指定备用模型。手动重试仍默认仅对本次生效。

获取失败会提示鉴权、网络或接口问题，并保留原来的模型值。部分供应商不提供模型列表，或返回的列表不完整，此时可继续手动填写。切换供应商、Key 或地址后，会清掉旧连接的候选；正在返回的旧列表不会填入新连接。

模型列表不等于用途认证：视频主分析的模型需要支持图像输入，音频转录的模型需要支持转录。获取列表只读取候选，不发送视频帧或执行分析。
